# anatomy — 让 Agent 把技术概念画成一台能动的机器

　　你让 agent 给文档配一张解释原理的图，它给你一堆方块和箭头；自己开 draw.io 画，折腾一小时还是流程图。anatomy 换了条路：不画图，先发明一台机器，让这台机器的运转方式就是那个概念本身。
　　10 月 8 日建仓，今天 12,869 stars、936 forks，MIT 许可。作者 Ryan 在 X 上的发布帖跑出百万级浏览，Vercel Labs 的 skills CLI 一条命令装进 Claude Code、Codex、OpenCode、Antigravity 和 MiniMax Code。

![[anatomy-demo-1.webp]]
*`examples/raptor-engine`，light 主题，点火瞬间。发动机与试车台是 SVG，尾焰是跑在同一等距相机里的 WebGL shader。*

### 它解决什么问题

　　技术写作里"机制"类概念最难配图：token bucket、数据库连接池、CDN 缓存命中、GPU context 复用。画成方块箭头能表达顺序，表达不了"为什么这么设计"；让 LLM 直接吐 SVG，得到的是一眼假的示意图，配色塑料、比例失真。
　　anatomy 的解法是把概念翻译成机械隐喻，再把那台机械精密地画出来、让它动起来。缓存 key 在内容没变时跳过工作，变成一把弹子锁：只有每根弹子都对上，锁芯才转动。一个 GPU context 服务 16 个 canvas，变成一台龙门绘图仪：唯一的打印头依次巡过 16 个孔位。隐喻由 Claude 自己发明，这是整个技能里工作量最大的部分，官方也建议把这件事整个交给它。

### 核心原理

　　SKILL.md 定的工作流：先收集真实数字（尺寸、数量、速率、阈值），发明物件，列部件清单、规划世界，然后调 kit 构建几何、从后往前逐层绘制、装进带标题和 live readout 的卡框，加上指针和键盘交互，最后像批评家一样自检，放大每个关节挨个看。
　　产出分三种形态。SVG 是核心：四色调的实体等距零件，输出可以是独立 HTML 页、单个内嵌样式的 .svg 文件，或 React / Next.js 组件。SVG + WebGL 用来画线条画不了的东西：火焰、尾焰、水、焦散、灯光。shader 跑在同一等距相机下的 canvas 里，夹在前后两层 SVG 之间，火"长"在画面里而不是浮在上面。3D 是 beta：转盘、弯指、掉落部件按帧重投影重着色。
　　kit 目录是随技能附带的绘图库，零 npm 依赖：iso-kit（等距相机、实体、部件库、SVG 渲染器与卡片样式）、lathe.mjs（任意轴回转体）、tube.mjs（管道线缆）、gl.mjs（WebGL 层）、turn*.mjs（3D 运行时）。
　　自检是它区别于"AI 画图"的地方。audit.mjs 做几何证明：没有管子穿过任何物体、每个端点都坐在支架上、每一处重叠都按深度顺序绘制。headless Chrome 里的 capture.mjs、drive.mjs 出截图、特写和慢放接触印相，lines.mjs 让任何悬空的线直接报错。图上每个读数都来自驱动零件的同一个小模型，不是贴上去的装饰数字。

### 安装配置

```sh
# Claude Code 全局安装（-a 跳过选择 agent 的交互）
npx skills add wheresryan22/anatomy -g -a claude-code

# 只装进当前项目
npx skills add wheresryan22/anatomy
```

也可以 git 直接放进技能目录，省掉 CLI 的 Node 版本要求：

```sh
git clone https://github.com/wheresryan22/anatomy.git ~/.claude/skills/anatomy
```

装完直接用：

```text
/anatomy explain how a token bucket rate limiter works, interactive
```

　　Codex 里是 `$anatomy`，OpenCode、Antigravity、MiniMax Code 用同样的 `/anatomy`。Claude Code 在运行中的会话也能拾取新技能，`skills` 目录是本次才建的则跑一次 `/reload-skills`。环境要求：Node ≥ 20.10（skill 本体零依赖，只用 Node 内置模块），Chrome 或 Chromium 用于自检（自动找常见安装位置，找不到就设 `CHROME_PATH`），React 输出需要 React 18+。

### 使用指南

　　官方给了三条出好图的心法：说想法不说画法，把真实数字给足；或者直接点名你要的机器和它该动的地方；再或者说明它将来住在哪。

#### 场景一：给项目文档配一张机制图

```text
/anatomy a figure for our Next.js docs on database connection pooling: a pool of 10 connections, requests borrow one and give it back, and when all 10 are busy new requests wait in a queue. A React component plus a static HTML preview, dark theme.
```

　　预期结果：一台有 10 个泊位的机械装置。请求进来取走一个连接、用完归还，10 个都占着时新请求滑进排队轨道。悬停能看到零件拆开，live readout 显示当前占用数。输出是 React 组件加一份静态 HTML 预览，几何模块、server 组件和 client 交互组件都是你能改的源码。

#### 场景二：把有流体和光的概念画活

　　火焰、水波、尾焰这类东西线条画不出来，anatomy 在这一层挂 WebGL：shader 跑在它自己的等距相机里，和 SVG 处在同一坐标系。官方示例里最直观的是本生灯，转动空气环，怠惰的黄色火焰变成咆哮的蓝色锥焰：

```text
/anatomy a Bunsen burner on a lab bench: opening the air collar turns the lazy yellow flame into a roaring blue cone. WebGL for the flame, one HTML file, dark theme.
```

　　ripple tank 示例叠了两层 WebGL：灯的光和纸面上的焦散、水面的反射，全部由公开的色散与光学模型驱动。

![[anatomy-demo-2.webp]]
*`examples/ripple-tank`：SVG 器材叠两层 WebGL（灯与纸面焦散、水面反射），44° 俯视。*

#### 场景三：把概念做成落地页的 hero

　　三种输出形态里，独立 HTML 适合放文档站，React 组件直接进现有前端。官方 test-rig 和 spot-plate 两张图就是从生产 React 站点上搬来的：玻璃按钮落在弹簧滑座上、探针压出倾角、读数表显示偏移。咖啡机是另一个交互密度更高的 demo：

```text
/anatomy a heat-exchanger espresso machine with the side panel off: boiler, heat-exchanger tube, group head, pump, steam wand and gauge. Show the water flowing when you pull a shot. Standalone HTML, light theme.
```

　　预期：侧板拆开的机器全貌，拉一杯时水从锅炉经热交换管到冲煮头，蒸汽棒的路径完整可见。

![[anatomy-demo-3.webp]]
*3D 模式（beta）：约 90 个零件在拖动转盘时逐帧重投影、重着色。*

### 进阶技巧

　　`node build.mjs --audit` 跑几何审计，证明没有管道穿透物体、所有端点有支撑、重叠绘制顺序正确。做 raptor-engine 那种 11 个总成、密排管道的图时，这是唯一靠谱的验收方式。
　　做好一张图可以发布到社区画廊：对 agent 说 "publish this figure to the Anatomy community gallery"，它会向你要标题和 GitHub 用户名、展示将发送的内容，经确认后自动向 anatomy-community 仓库开 PR，不用会 git。
　　examples/ 目录里有 8 张完整成品图，构建页面都已提交，打开任意 .html 就能交互。想学结构从 dial-indicator 看起，约 300 行，是这套 kit 的最小范例。

### 常见踩坑

　　它是故意慢的。官方在 Limits 里写得很直白：一张 Figure 要 30 到 90 分钟，Hero 级 2 到 4 小时，Epic 级 6 小时以上（开工前会先跟你确认）。时间花在发明物件、雕零件、跑审计和逐关节检查上。想要"10 秒出图"的工具，这个不是。
　　`npx skills add` 对 Node 版本比 skill 本体更挑：v1.7.1 的 skills CLI 要求 Node 22.20+，anatomy 自己 20.10+ 就能跑。npx 崩了先升 Node，或者绕开 CLI，直接 git clone 到技能目录。
　　Codex 用户的沙箱会拦自检启动的 headless Chrome，图照样建好，只是检查失败。按需批准那条命令、改 config.toml 开 network_access，或者自己开普通终端跑 `node scripts/capture.mjs page.html --out shots/page.png`。

## 今日小结

　　写技术博客、维护文档站、做讲解视频或教学材料的人，anatomy 值得今天就装。一条 npx 命令，不用 API key，不用 npm install。给它一个概念和几个真实数字，等它把机器发明出来、把零件雕完、把审计跑绿，你拿到的是一张能交互、能嵌入、源代码归你所有的工业风插图。代价它写在明面上：它慢，而且慢得理直气壮。
