## 1. GLM-5.3-Flash「牛来」（智谱认领匿名模型 Ox-Alpha，全球开源）

![[glm-flash-demo.png]]

**评分: 9.6/10 | 可操作性: 高 | 热度: 8-26 晚正式认领+开源，量子位/新浪/DoNews/SmartHey 多家报道；匿名期登顶 OpenRouter 与 OpenCode 双平台调用量榜**

**是什么：**
智谱 8 月 26 日晚认领了此前海外疯传的匿名模型 Ox-Alpha（中文社区叫「牛来」），正式发布并开源 GLM-5.3-Flash。320B 总参数、18B 激活参数，是 GLM-5 系列首个原生多模态模型，也是首个采用「线性注意力 + 稀疏注意力」混合架构的开源前沿模型。线性注意力递归捕获局部依赖，稀疏注意力用轻量级索引器召回全局上下文，再加 IndexPool 把索引器 4 个缓存向量压成 1 个。训练语料为智谱自研 30T Token 多模态数据，62T Tokens 全部跑在国产芯片上；推理侧则是 Encode-Prefill-Decode 分离式架构加 Layer Split、混合缓存量化，端到端性能比同硬件基线提升 3 倍。官方还配套了 Visual Coding 数据合成流水线，让模型写代码时能看最终页面和 3D 场景，边写边看边改。

**怎么用：**
```bash
# 方式一：API（OpenAI 协议，model code 为 glm-5.3-flash，1M 上下文）
# Z.ai 控制台建 Key：https://docs.z.ai  ；国内用 BigModel：https://open.bigmodel.cn
curl https://api.z.ai/api/paas/v4/chat/completions \
  -H "Authorization: Bearer $ZAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"glm-5.3-flash","messages":[{"role":"user","content":"给这段视频逐人配上字幕"}]}'

# 方式二：本地部署（开源权重，llama.cpp/Ollama/LM Studio 均有量化版）
docker model run hf.co/zai-org/GLM-5.3-Flash
```

**为什么重要：**
Artificial Analysis 综合智能指数 57 分，与 Claude Opus 4.8 持平；定价是 GLM-5.3 的 1/10，首发期低至 Opus 4.8 的 1/40。架构效率的账是：相比 GLM-5.3，注意力单 Token 计算量降 3.01 倍，KV Cache 缩 4.44 倍；320B 总参数全面超过上一代体量大得多的 GLM-5.2。配合一个更硬的事实：匿名测试期间 OpenRouter 和 OpenCode 上的全部推理请求都由国产芯片集群承接，单 Token 成本已做到与英伟达 GPU 相当。

**讨论现场：**
- 匿名期海外开发者用 tokenizer 指纹和 Bloomberg 的分析猜背后出身，没人猜中是国产全栈。认领后量子位的总结是：「能干活，吃得少。这回牛是自己的，草也是自己的。」
- 社区对「1/40 价格 + 开源 + API」的组合反应最集中：Agent 长任务跑几十分钟，token 流水账是真实成本，这个价格让长任务第一次不用先算账。
- HF 模型卡自述：320B 总参、18B 激活，benchmark 全面超过 GLM-5.2，编码与 agent 基准接近 Claude Opus 4.8。

**来源：** https://www.qbitai.com/2026/08/479919.html · https://huggingface.co/zai-org/GLM-5.3-Flash · https://docs.z.ai/guides/vlm/glm-5.3-flash

## 2. archify（让 Agent 画可验证架构图的 skill，单日破千星）

![[archify-demo.png]]

**评分: 9.0/10 | 可操作性: 高 | 热度: GitHub Trending +1,035 stars/day，总星 18.1K；Trendshift 在榜**

**是什么：**
tt-a1i 的开源 agent skill（MIT）：把代码库或系统描述转成交互式技术图，在对话里直接生成。五种图型：架构、工作流、时序、数据流、生命周期。背后是 Typed JSON 中间表示加确定性校验，agent 控制层级、间距、路由和强调，产出物是自包含 HTML（可导出 PNG/SVG/WebM 和 1200×630 分享卡）。最有工程感的是 Architecture Delta 模式：对 PR 生成 Before/Delta/After 三张快照，把「新增、删除、变更、移动、重路由」的事实差异直接画出来，用于代码评审。还有一个候选品机制：新产物必须先过 schema、布局、HTML/SVG、路由、标签五重检查，全部通过才替换 last-known-good 文件。

**怎么用：**
```bash
# 全局安装（Claude Code / Codex / Cursor / OpenCode / Raven）
npx skills add tt-a1i/archify -g
# 免安装试用
npx skills use tt-a1i/archify@archify --agent codex
# 之后直接说："Use archify to map this repository's runtime architecture."
```

**为什么重要：**
此前让 agent 画架构图的主流路径是 Mermaid：生成快，布局糙，长一点的图就得人手调。archify 把「agent 控制布局 + 类型化交付 + 越过检查不发布」做成工程闭环，节点还能链接到 Git 固定 commit 的文件做来源证据。18.1K 星里今天一天进账 1,035，在 skill 生态连续霸榜多日的背景下，它是本周少数靠「单点做深」而非「打包合集」冒头的新项目。

**讨论现场：**
- Trendshift 简介：「beautiful, verifiable architecture, workflow, sequence, data-flow, and lifecycle diagrams in a single HTML file」。
- 社区对 Architecture Delta 的反响集中在 PR review：以前看架构改动靠 git diff 硬读，现在直接看三帧对比图。
- README 声明它与 Mermaid 的分工：Mermaid 适合快速出图，archify 适合「要拿去评审、要存档、要分享」的图。

**来源：** https://github.com/tt-a1i/archify

## 5. Accept: text/markdown（同一 URL 给 Agent 发 Markdown，HN 94 分）

**评分: 8.0/10 | 可操作性: 高 | 热度: HN 首页 94 points / 52 comments，8-27 早 6 小时前发布**

**是什么：**
acceptmarkdown.com 把一个 HTTP 老机制搬进 AI 时代：内容协商。同一 URL，请求带 `Accept: text/markdown` 就返回 Markdown，浏览器不带就照常返回 HTML。四大正确性要点：给 Markdown `Content-Type: text/markdown; charset=utf-8`、响应带 `Vary: Accept`、不支持的媒体类型回 406、正确处理 q-values。网站配了一个就绪检查器（从边缘节点探测你的站点是否 AI-ready）和 17 套框架/服务器的复制即用配方：Nginx、Caddy、Apache、Cloudflare Workers、Next.js、Astro、SvelteKit、Nuxt、Express、Laravel、Rails、WordPress、Discourse、Django 等，还有一张「哪些 agent 会发这个头」的支持矩阵。

**怎么用：**
```bash
# 先测你的站点今天是不是 AI-ready（会返回 HTTP 头，看 Content-Type 与 Vary）
curl -sI -H "Accept: text/markdown" https://你的域名/文章
curl -s  -H "Accept: text/markdown" https://你的域名/文章
# 配方直接抄（含 Cloudflare 零配置捷径）：
# https://acceptmarkdown.com/recipes/
```

**为什么重要：**
已经有一批 agent 在发这个头：Claude Code、OpenCode、OpenClaw 请求网页时都会带 `Accept: text/markdown, text/html`。Pronovix 的实测数据：Markdown 表示比渲染 HTML 压缩后小约 74%，同一 URL 省 3 倍以上抓取量。它和 llms.txt 路线的区别：不另开文件，同一地址内容协商，SEO、书签、RSS 全不受影响。

**讨论现场：**
- HN 讨论里最值钱的是实现陷阱：wempe.dev 的补充文章列了 `accept.includes("text/markdown")` 子串判断的四种错法，比如 `text/markdown;q=0` 时子串匹配命中但正确结果是应该回 HTML。
- 评论共识是「这是给未来十年的 AI 抓取修路」：成本接近于零，文档站收益最大，检查器可以在 30 秒内告诉你当前状态。

**来源：** https://acceptmarkdown.com · https://news.ycombinator.com

## 6. Agnes Video 2.5 上线 Pavo（免费 AI 短剧工作流，中文圈热帖）

新加坡 Sapiens AI 旗下 Agnes AI 的 Video 2.5 系列正式上线自家免费创作平台 Pavo：量表 Flash 版不消耗积分，用自产模型生成图片和视频全部免费。2.5-preview 相对 2.0 的升级：生成速度翻倍、运镜与多镜头叙事更顺滑（官方对标 Veo 3 方向）、支持多张参考图锁定人物外观与商品细节、修复画面字幕乱码、强化物理规律还原（减少漂浮、穿模）。Pavo 的工作流是 Agent Native 的：一句话出需求，自动展开大纲、角色场景道具设计、分镜、关键帧、分镜视频，每步人工确认后再走下一步；第三方模型（Seedance、Kling 等）需要会员，自产模型分文不取。自 6 月 1 日起 Agnes 全模态 API（文本 1M 上下文、图像 4K、视频）也面向开发者无限期免费。

## 7. claude-plugins-official（Anthropic 官方插件目录仓库，34K 星）

**评分: 7.4/10 | 可操作性: 高 | 热度: GitHub Trending +308 stars/day，总星 34.4K**

**是什么：**
Anthropic 管理的官方 Claude Code / Claude Cowork 插件目录：`marketplace.json` 列出官方维护的插件，内容由内部评审管线同步，第三方 PR 会被自动关闭。它和 8-24/8-25 日报收录的 claude-plugins-community（审核后的社区插件镜像）以及 knowledge-work-plugins 构成三级体系：官方维护、社区审核、角色化知识工作。命令行里用 marketplace 标识区分安装来源。

**怎么用：**
```bash

claude plugin install <plugin-name>@claude-plugins-official
# 查看可安装列表
claude plugin list
```

**为什么重要：**
8-24 社区版收录时只有 993 星，one day 起量靠的是「终于有带审核的分发渠道」的预期。官方目录 34.4K 星则是另一种信号：Anthropic 把插件分发的供应链（提交、扫描、批准、分发）做成基础设施后，开发者对「官方渠道 = 可信赖来源」这个等式买了单。对把 agent 插件当生产依赖的团队，marketplace 标识就是审计入口。

**讨论现场：**
- 社区讨论里它与 community 版的分工被反复确认：一个管官方维护的稳定版，一个管社区投稿的审核分发。
