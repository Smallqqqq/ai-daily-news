## 1. awesome-gpt-image-2（GPT-Image2 工业级提示词引擎与模板库）

**评分: 9.0/10 | 可操作性: 高 | 热度: GitHub +2,449 stars/day（今日最高单日增量），总 15.7k★，Trendshift 实时榜第 1**

**是什么：**
freestylefly 维护的 GPT-Image2 提示词资产库，思路是"Prompt as Code"：把 532 个社区案例逆向工程成结构化提示词，加上 20+ 套工业级模板，按 12 个类别归档（海报排版 86 例、摄影写实 77 例、UI 界面 73 例、图表信息图 52 例等）。提示词被拆成主体、光照、材质、布局、视觉细节等可组合的原子 schema，配套一个 Agent Skill（`gpt-image-2-style-library`），供 Claude Code、Codex、Cursor 等 agent 选风格、套模板。另有可视化网站 gpt-image2.canghe.ai 可浏览画廊、复制提示词，Google 登录后直接生成。

**怎么用：**
```bash
# 方式一：Agent Skill 安装（Claude Code / Codex）
npx skills add freestylefly/awesome-gpt-image-2 --skill gpt-image-2-style-library --agent claude-code codex --global --yes --copy

# 方式二：npm CLI 全局安装
npm install -g gpt-image-2-style-library
gpt-image-2-style-library install all

# 方式三：克隆仓库自己翻案例
git clone https://github.com/freestylefly/awesome-gpt-image-2.git
```

**为什么重要：**
图像模型的能力边界在 2026 年已经从"会不会画"移到"能不能稳定执行长指令"。这个库解决的是 GPT-Image2 提示词的组织问题：官方只有散文式 prompt，社区案例散落各处，agent 无法程序化调用。532 个案例 + 原子化 schema 意味着批量生成、模板系统、生产工作流可以直接落地。15.7k stars 用一周多时间积累，+2,449/day 的单日增量在今天全部 GitHub 仓库中排第一。

**讨论现场：**
- Trendshift 实时榜将它排第 1，简介被社区概括为"Prompt as Code | 工业级提示词引擎与模板库，530+ 个案例逆向工程"。
- 中文社区（知乎 AI 图像话题）同期讨论"图像生成里的思维链：DPO 与 GRPO 对比"等选题，提示词工程正在从手工经验变成可交易的资产。

**来源：** https://github.com/freestylefly/awesome-gpt-image-2

## 3. munder-difflin（本地多 agent 蜂巢：一屋子你的克隆体）

![[munder-difflin-demo.png]]

**评分: 8.4/10 | 可操作性: 高 | 热度: GitHub +795 stars/day，总 4.1k★，2,881→4.1k 一周内翻倍**

**是什么：**
chaitanyagiri 用 Electron + React + TypeScript + Pixi.js 写的本地多智能体调度台，口号是 "Agent harness to run an office of your clones"。它把你已付费的终端编码 CLI（Claude Code、Codex、Gemini CLI、Cursor、Kimi Code 等 12 家）包装成真实进程中的 agent，放进一个共享"蜂巢"协作。用户只和核心编排者 GOD agent（Michael）对话，由它把任务路由给其他 agent，花费、范围、破坏性操作可设人工门禁，支持三级熔断（steer → constrain → stop）和 per-agent git worktree 隔离。每个 agent 在 Pixi.js 地板上是一个像素角色，带记忆、文件邮箱、共享黑板和只追加事件日志。

**怎么用：**
```bash
git clone https://github.com/chaitanyagiri/munder-difflin.git
cd munder-difflin
npm install        # postinstall 会针对 Electron ABI 重建 node-pty
npm run dev        # 启动 Electron 应用（Windows/macOS 亦有安装包，见 releases）
```

**为什么重要：**
多 agent 协作此前多走云端编排（如 Orca、Cloud Mode），munder-difflin 把整件事拉回本地：复用你已有的各家订阅额度，不新增模型账单，token 预算和真实成本有 OTel 遥测。4.1k stars 的小仓库拿下 +795/day，说明"用我自己的额度跑一支 agent 小队"切中了订阅疲劳的开发者。技术栈上有两个细节：node-pty 让终端 agent 是真实进程而非 API 模拟；只追加事件日志 + 单提交者 git 让多 agent 并行写文件不冲突。

**讨论现场：**
- Trending 页面的社区描述收敛为 "local multi-agent harness"，与同日上榜的 amadeusprotocol/node（+1,397/day，Rust）并列为本周本地 agent 基础设施的两个新面孔。
- 仓库 README 的 ASCII 架构图展示了双平面设计：Renderer（React + Pixi 地板 + 终端）经 IPC 与 Event/Terminal 两个 plane 通信，再落到 CLI 进程。

**来源：** https://github.com/chaitanyagiri/munder-difflin

## 8. Maka（Apache 孵化器的 local-first AI Agent 工作区）

**评分: 7.5/10 | 可操作性: 中 | 热度: GitHub +411 stars/day，总 2.9k★（Apache Incubating 新项目）**

**为什么重要：**

## 9. claude-obsidian（Obsidian + Claude Code 自组织第二大脑）

**评分: 7.4/10 | 可操作性: 中 | 热度: GitHub +310 stars/day，总 11.9k★**

**是什么：**
AgriciDaniel 开发的 Claude Code 插件 + 15 个 Agent Skills 组成的知识库系统，把 Obsidian vault 变成 Claude Code 的自组织第二大脑。设计遵循 Karpathy 的 LLM Wiki 模式，以 kepano/obsidian-skills 为基座。工作流是：捕获来源 → 保存不可变副本 → 生成带引用的笔记 → 链接/索引/MOC → 复用查询。每次写入是一次可恢复事务：先读目标记录 SHA-256，工人只返回草稿，编排者单次合并，冲突绝不静默覆盖。

**怎么用：**
```bash
git clone https://github.com/AgriciDaniel/claude-obsidian.git
cd claude-obsidian
# 初始化 vault（先出计划，人工审核后再 --apply）
python3 scripts/claude-obsidian.py init "$HOME/Documents/MyKnowledgeVault" --apply
# 从 vault 目录启动，插件生效
cd "$HOME/Documents/MyKnowledgeVault"
claude --plugin-dir /absolute/path/to/claude-obsidian
```

**为什么重要：**
Obsidian 用户群体和编码 agent 用户群体高度重合，这个项目把"让 agent 长期维护你的笔记库"从演示变成了有事务保证的工程方案。11.9k stars 的体量在 Obsidian 生态插件里少见，+310/day 保持稳定。信任架构是最大亮点：工人（worker）只产出草稿，编排者（orchestrator）单点合并，配合 SHA-256 校验，杜绝 agent 悄悄覆盖你的笔记。

**讨论现场：**
- README 明确声明能力边界：PDF/EPUB 只做元数据不提取正文，图片仅取哈希与尺寸，高风险声明要求两个独立来源——这种"诚实的边界"在社区评价里被反复提到。
- 15 个技能中 `wiki-lint`（死链/孤立页/元数据检查）、`wiki-mode`（Generic/LYT/PARA/Zettelkasten 归档模式）最受 Obsidian 用户关注。

**来源：** https://github.com/AgriciDaniel/claude-obsidian

## 10. SenseNova U1.5 Lite（商汤 8B-MoT 统一多模态模型正式开源）

![[sensenova-demo.png]]

**评分: 7.3/10 | 可操作性: 中 | 热度: 知乎 GitHubDaily 首发 72 条评论，HF 模型页上线当日，8-24 正式版发布**

**是什么：**
商汤 2026-08-24 正式开源的轻量级原生统一多模态模型，NEO-Unify 架构去掉了 VAE，在像素层面端到端联合建模语言、视觉语义与像素生成。8B-MoT 规模原生支持 4K 输出、3-4k 字符超长指令遵循（多数开源模型超过 1k 字符指令就会漏细节）、中英文排版、Bounding Box / Visual Marker 精细编辑，以及多轮迭代修改不跑偏。

**怎么用：**
```bash
git clone https://github.com/OpenSenseNova/SenseNova-U1.git
cd SenseNova-U1
uv sync
source .venv/bin/activate
# 文生图（HF 权重 sensenova/SenseNova-U1.5-8B-MoT，推荐 16GB 显存）
python examples/t2i/inference.py --model_path sensenova/SenseNova-U1.5-8B-MoT \
  --prompt "A cinematic mountain lake at sunrise, realistic photography." \
  --width 2048 --height 2048 --device_map auto --output output.png
# 编辑模式
python examples/editing/inference.py --model_path sensenova/SenseNova-U1.5-8B-MoT \
  --image input.png --prompt "Change the jacket to cobalt blue." --output edited.png
```

**为什么重要：**
