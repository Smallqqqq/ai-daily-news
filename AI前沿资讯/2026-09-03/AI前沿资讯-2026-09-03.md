## 1. Gemini 3.8 Flash / 3.8 Flash Cyber — 20 天一发，价格一分没涨

**评分: 9.5/10 | 可操作性: 高 | 热度: HN 839 points / 488 comments，X 相关推文 289K+ 观看**

**是什么：**
Google 于 9 月 2 日发布 Gemini 3.8 Flash，距 3.7 Flash 上线仅 20 天，43 天内第三个 Flash 版本。1M token 上下文，文本/图像/视频/音频/PDF 全模态输入，定位长时程软件工程和自主 agent 任务。同时发布 3.8 Flash Cyber 安全变体，专做漏洞挖掘和自动打补丁，通过 Fairwind Program 限定向政府与可信防御方开放。Wiz（Google 以 320 亿美元收购）在内部渗透测试基准上实测：Cyber 变体对真实漏洞的召回率高 7.5%-9.7%，成本只有前沿模型的 1/2.3 到 1/5.2；Google Cloud Vulnerability Research 用它 2 小时内挖出一个关键基础漏洞，平时这类工作要数月。

**怎么用：**

**为什么重要：**

## 3. anthropics/commerce-agents — Anthropic 官方开源电商 Agent 蓝图

**评分: 8.8/10 | 可操作性: 高 | 热度: X 官方推文 27.5K 观看，中文科技圈次日拆解刷屏**

**是什么：**
Anthropic 把过去一年给企业落地电商 Agent 的整套方法论和代码模板开源了。拆成两个 Agent：Shopping Agent 嵌进商家 App/网站，负责搜索、比价、个性化推荐、加购、订单查询和售后；Merchant Agent 给内部员工用，做销售分析、库存管理、调价和促销设计，涉及真实改动商品/价格的操作先进 staging，必须人工批准。附零售、旅游、电信、娱乐四套可运行参考实现。架构按 Anthropic 当前的标准展开：Claude + Agent Loop + Tools + Skills + Memory + Guardrails + Evals，没有多 Agent 路由的花活。前端商品卡片、行程单这类 UI 也被建议做成 Tool 让模型调用结构化组件，而不是生成文本再让前端解析。

**怎么用：**
```bash
git clone https://github.com/anthropics/commerce-agents.git
cd commerce-agents
# 用配套 Claude Code 插件从零生成自己的电商 Agent：
# 对话里输入 /scaffold-commerce-agent "a shopping assistant for our store"
# 插件会询问技术栈，然后生成 Agent、添加流程、写 Eval、Review 现有 Agent
```

**为什么重要：**
Anthropic 披露的真实客户数据：使用 Claude Shopping Agent 的零售商购物车金额最高提升 35%，完成购买概率最高提升 60%。Shopify、Priceline 已在用 Claude 搭类似体验。更关键的是定位声明：Anthropic 明确不做商城、支付和广告，只占中间那层智能——Catalog、Checkout、供应链留给商家。这套蓝图把"怎么在企业里落地 agent"从咨询交付变成了可 fork 的代码。

**讨论现场：**
- X 上 @sidtweeted："我会去验证那个 35% 的说法，我运营着 50 家电商店铺。"——客户数据的真实性成为讨论焦点
- 中文科技圈拆解（Max For AI）："人类花了二十多年发明电商网站，现在模型正在把搜索框、商品详情页、筛选器和客服一起吃进去。"
- 讨论的普遍结论：每个 Shopify 商店未来都拥有自己的 Agent，但底下跑的是 Claude

**来源：** https://github.com/anthropics/commerce-agents

## 4. pacifio/atlas — 多 agent 的"源码控制"：每个改动可追溯到哪次对话

**评分: 8.5/10 | 可操作性: 高 | 热度: GitHub Trending 单日 +888 星（总 2.9K，新仓库爆发）**

**是什么：**
pacifio 团队做的 Rust/Tauri 桌面应用，解决"让多个编码 agent 协作时丢失上下文"的问题。Claude Code 和 Codex 作为外部子进程通过 ACP 运行，内置 agent 跑在自研 Rust agent 框架 Cersei 上，Cursor、OpenCode、Kilo Code 等 ACP 注册表里的 agent 也能自动拉取官方二进制接入。每次改动都链接回产生它的会话、当时的 prompt 和 agent 的操作步骤；所有 agent 共享一份记忆（进行中的计划、决策、文件变更、失败记录），语义检索在设备端完成。代码和笔记默认留在本机，可选择与团队同步。

**怎么用：**
```bash
# 下载 macOS 版：https://tryatlas.cc 或 GitHub Releases（.dmg）
# Linux/Windows 可从源码构建（同一 Tauri 代码库，官方标注未测试）：
# 需要 Bun、Rust（rustup）、Xcode Command Line Tools
git clone https://github.com/pacifio/atlas.git
# 使用 Claude Code agent 需先装 claude CLI 并加入 PATH；内置 agent 无外部依赖
```

**为什么重要：**
多 agent 协作是 GitHub 热榜当前的主旋律，但"谁改了什么、为什么改"的记录一直是空白——agent 产出物只有墙一般的绿色 diff。Atlas 把审计能力做成了默认行为：prompt → 会话 → 改动全链路可追溯，agent 切换时通过会话交接包延续上下文。888 星/天的速度对一个 3 天前才上趋势榜的新仓库来说很猛，配套的 Rust SDK（pacifio/cersei，MIT）把 agent 构建拆成库函数，双层开源。

**讨论现场：**
- LinkedIn 上 Arthi Rajendran 的推荐贴："每个改动都链接回产生它的会话、你给的 prompt 和 agent 的步骤。切换 agent 不再丢上下文，你能审查真正落地的内容，而不是信任一面绿色文字的墙。"
- 社区关注点：ACP 注册表长尾 agent 的兼容性 QA 还在进行中，Windows/Linux 构建官方标注未测试

**来源：** https://github.com/pacifio/atlas

## 7. ponytail — 让 agent 像最懒的资深工程师一样思考

```bash
git clone https://github.com/DietrichGebert/ponytail.git
```

**为什么重要：**
单日 +1,354 星是今天 GitHub 全站最高增速。agent 时代真正的成本发生在代码写完之后——多一层抽象、多一个没用的工具函数，都是长期维护债务。这个项目把"克制"做成了可注入的规则集，121.7K 星说明开发者群体对"少即是多"的共识在扩大。它是今日热榜上最便宜的一类工具：零安装、纯提示词，当天就能用。

**讨论现场：**

## 10. 星火 X2.5-4B / 1.7B — 4B 端侧模型在 agent 基准上越级打怪

**评分: 7.5/10 | 可操作性: 高 | 热度: 知乎新智元 09-02 报道，权重全开源（HF/ModelScope/GitHub）**

**是什么：**
科大讯飞 9 月 1 日在 Hugging Face 上线两个端侧模型：星火 X2.5-4B 和 1.7B，权重、代码仓库、部署文档全开源，MaaS 平台 API 同步上线并限时免费。定位是给断网设备装一个"真能干活"的引擎：车机、音箱、产线机器人这些算力紧张、网络时断时续的场景。9 月 7 日科大讯飞还将发布旗舰通用大模型星火 X2.5。

**怎么用：**
```bash
# 下载权重（Hugging Face / ModelScope 均可）

# GitHub 仓库含部署代码：https://github.com/（仓库名 Spark-X2.5）
# 或走 MaaS 平台 API（限时免费）
```

**为什么重要：**
4B 参数在 agent 基准上打出了跨体量的成绩：多轮工具调用 τ³-bench 30.4（几十步操作容错是端侧模型的传统短板），MCP 协议测试 MCP-Atlas 54.6 为同尺寸最高，自主网页检索 BrowseComp 40.9，复杂指令遵循 IFBench 75.0。1.7B 版本在 MCP-Atlas 拿 23.4，同样是同尺寸第一档。这些数字的意义在于：agent 能力不再是大模型的专利，4B 模型能装进更多设备。
