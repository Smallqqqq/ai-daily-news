## 1. google/ax：Google 开源 Agent 编排运行时，单日 +1,543 stars

**评分: 9.2/10 | 可操作性: 中 | 热度: GitHub 1,543 stars/day，累计 9.2k stars / 438 forks**

**是什么：**
Google 开源的声明式 Agent 编排器，把「跑一个 Agent」变成提交一份 YAML。四个原语：`Task` 在沙箱里跑不可信 Agent 代码并限制 CPU/内存；`Workspace` 预挂 Git 仓库、MCP server、skill 包，Agent 一启动就是热的；`Gateway` 把出网流量锁死在显式主机白名单；`Model` 配置平台自己用哪个 LLM，凭据来自 Kubernetes secret。CLI 是 kubectl 形状（`apply`/`get`/`describe`/`watch`/`delete`），走 gRPC 连控制面，跟随当前 kube context。

**怎么用：**
```bash
go install github.com/google/ax/cmd/ax@latest

make deploy AX_IMAGE_REPO=<your-registry>   # 部署控制面到 ax-system
ax apply -f examples/task.yaml
ax get tasks
ax ssh task123 -- ls -la /workspace          # 进沙箱看 Agent 在干什么
ax suspend task task123                      # 挂起空闲 Agent
ax resume task task123                       # 从原地恢复
```

**为什么重要：**
此前让 Agent 上生产要自己拼沙箱隔离、网络策略、状态持久化三套东西，ax 把它们收进一个控制面，官方定位是单集群跑十亿级 Agent 任务。代价是它需要 Kubernetes 集群加 Agent Substrate 控制面，本地跑不起来。README 明确标注核心概念和协议「会有重大破坏性变更」，Releases 区还是空的，没有正式版本号。

**讨论现场：**
- 同日 GitHub 上 Google 两个仓库同时上榜：google/ax 1,543 stars/day 与 agent-substrate/substrate 558 stars/day，构成「运行时 + 编排器」两层
- 仓库 39 个 open issue、0 个 open PR，作者在 README 顶部主动挂了 breaking changes 警告，说明还在概念打磨期

**来源：** https://github.com/google/ax

## 2. dream-num/univer：给 AI Agent 用的 Office 引擎，+1,142 stars

![[univer-demo.png]]

**评分: 8.8/10 | 可操作性: 高 | 热度: GitHub 1,142 stars/day，累计 16.4k stars / 1.4k forks**

**是什么：**
Univer 原本是开源 Office SDK（表格/文档/幻灯片），这次榜单简介改成了 "The Office Harness for AI Agents"。关键能力是能在 Node.js 里 headless 跑：工作簿逻辑、公式引擎、文档模型都不依赖浏览器，适合放进 Agent 和 server 端工作流。Agent 通过统一 Facade API 读写工作簿、区域、公式和文档，浏览器和 Node.js 一套接口。

**怎么用：**
```bash

# 本地跑起来看
git clone https://github.com/dream-num/univer.git
cd univer && pnpm install && pnpm dev
```

**为什么重要：**
Agent 处理 Excel 一直是短板，要么调闭源 API，要么自己啃 xlsx 格式。Univer 提供完整公式引擎，Agent 改完还能通过渲染截图和布局诊断自检结果，不必靠人工验算。同时支持 worktree 式协作：Agent 在隔离草稿里改，人来决定合并哪些。16.4k stars、5,804 commits、Apache-2.0，表格是当前最成熟的产品面，Docs 和 Slides 共用同一架构。

## 5. agent-substrate/substrate：Agent 沙箱运行时，+558 stars

**评分: 8.4/10 | 可操作性: 中 | 热度: GitHub 558 stars/day，累计 3.5k stars / 416 forks**

**是什么：**
Google 的 Agent 执行运行时，把大量「actor」（Agent 应用）映射到少量「worker」上。出发点很实在：Agent 大部分时间在等 LLM 返回，没必要每个会话都占一个容器。隔离靠 microVM 和 gVisor，做原生零信任的内核与网络隔离。在 Kubernetes 的 Pod 和自动伸缩之上加了 Agent 专用调度。框架无关，README 列了 ADK、LangChain、Claude Code、CodeX 和沙箱化 MCP server 的兼容性。

**怎么用：**
```bash
# 本地 kind 集群跑通
hack/create-kind-cluster.sh
hack/install-ate-kind.sh --deploy-ate-system
hack/install-ate-kind.sh --deploy-demo-counter
go install ./cmd/kubectl-ate

kubectl ate create actor my-counter-1 -a ate-demo-counter --template counter
kubectl port-forward -n ate-system svc/atenet-router 8000:80
curl -X POST -H "ate-target-actor: ate-demo-counter/my-counter-1" -i http://localhost:8000/
```

**为什么重要：**
官方给的数字是比标准容器运行时高 10 倍密度、resume 低于 500ms、每秒 500 次以上 suspend/resume。这是 Agent 上云的真实瓶颈所在，不是模型慢，是每个会话都占着资源不放。要注意 README 明说「还不能用于生产」，API 会变，也不是 Google 官方支持产品。3.5k stars / 978 commits / Apache-2.0。

**讨论现场：**

**怎么用：**
```bash
curl -fsSL https://treg.to/install.sh | sh
treg login
treg catalog search "backlinks for a domain"
treg call tikhub.tiktok.user.profile --query uniqueId=tiktok
treg balance

# Claude Code 插件
/plugin marketplace add superdesigndev/treg
/plugin install treg@treg
```

**为什么重要：**

**讨论现场：**

## 10. Gemini 3.8 Flash TTS：130 语言加 30 秒声音克隆

**评分: 7.6/10 | 可操作性: 高 | 热度: HN 首页 255 points / 124 评论，9 月 23 日发布即上线 API**

**是什么：**
Google 在 9 月 23 日发布两个语音合成模型。Gemini 3.8 Flash TTS 面向创作场景（游戏、有声书、播客、互动媒体），支持 130 种语言；Gemini 3.8 Flash-Lite TTS 面向配音和批量音频，支持 101 种语言，替代 4 月的 gemini-3.1-flash-tts-preview。能力包括用自然语言描述生成全新音色、2000 多个现成音色库（含墨西哥西班牙语、魁北克法语、苏格兰英语等地区变体）、30 秒音频样本复刻声音（需通过同意验证，输出带 SynthID 水印和 C2PA 凭证）、脚本里直接写舞台指示和非语言元素如 `<laughs>`、`<sigh>`、`|mhm|`、单个脚本生成双人对话、以及数小时长音频的音色漂移控制。

**怎么用：**
```bash
curl -X POST "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.8-flash-tts:generateContent" \
  -H "x-goog-api-key: $GEMINI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"contents":[{"parts":[{"text":"<laughs> 用嘲讽的语气读这句话"}]}],
       "generationConfig":{"responseModalities":["AUDIO"]}}'
```
也可以直接在 Google AI Studio 里试听和调用。

**为什么重要：**
