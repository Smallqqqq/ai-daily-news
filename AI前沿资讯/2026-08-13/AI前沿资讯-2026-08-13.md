## 2. cathrynlavery/diagram-design（29 种编辑级图表的 Claude Code Skill，2,855 stars/day 登顶热榜）

**评分: 9.0/10 | 可操作性: 高 | 热度: GitHub 今日 Trending #1 · 2,855 stars/day · 10,743 总星**

**是什么：**
diagram-design 是一个 Claude Code Skill 包，内置 29 种编辑部级别的图表类型（架构图、流程图、时序图等），全部用自包含 HTML + SVG 实现。它的卖点写在 README 里：No shadows, no Mermaid-slop——不用 Mermaid，因为 Agent 生成的 Mermaid 代码经常渲染失败；不用阴影套模板，每种图表都是可直接放进文档的干净矢量图。2,855 stars/day 的增速是今天 GitHub 全站第一。

**怎么用：**
```bash
# 克隆并安装为 Claude Code skill
git clone https://github.com/cathrynlavery/diagram-design
mkdir -p ~/.claude/skills && cp -r diagram-design ~/.claude/skills/

# 之后在 Claude Code 中直接说：
# "画一张微服务架构图，说明支付服务的调用链"
# Agent 会生成自包含 HTML 文件，浏览器打开即用
```

**为什么重要：**
Agent 生成图表的现有方案都有硬伤：Mermaid 语法容易写错导致渲染失败，PlantUML 需要本地环境，截图类方案不可编辑。diagram-design 用"自包含 HTML+SVG"绕开整个问题——一个文件双击就能在浏览器看，还能继续改代码。2,855 stars/day 超过了当日第二名 msitarzewski/agency-agents 的 1,873，说明"让 Agent 输出真正能用的图"是开发者公认的痛点。

**讨论现场：**
- Trendshift 榜单把它列为今日 Live Trending 第一，描述是"29 editorial diagram types for Claude Code. Self-contained HTML + SVG"。
- 项目两天累计 10,743 星，前一天已有大量新增，热度在延续。

**来源：** https://github.com/cathrynlavery/diagram-design

## 4. stablyai/orca v1.4.180（多 Agent 并行 ADE 支持 Stacked PRs，1,235 stars/day）

**评分: 8.0/10 | 可操作性: 高 | 热度: GitHub Trending 1,235 stars/day · 43,968 总星**

**是什么：**
Orca 是 Stablely AI 的多 Agent 桌面开发环境（ADE），一个界面里同时驱动多个编码 Agent 干活。8 月 11 日发布的 v1.4.180 带来三个实用更新：GitHub Stacked PRs 支持（创建和管理堆叠 PR，带 stack map 和合并流）、手动 artifact 分享（从 HTML/Markdown 视图直接分享产物）、Agent 状态钩子实时开关（包括 WSL relay 下的 gating）。1,235 stars/day 排在今天 GitHub 热榜前列。

**怎么用：**
```bash
# 下载桌面安装包（macOS / Windows / Linux）
# 官网: https://stably.ai/orca
# 或从 GitHub Releases 获取:
# https://github.com/stablyai/orca/releases/latest
# 安装后用自己的 API Key 接入 Claude/GPT/DeepSeek 等模型即可开 Agent 舰队
```

**为什么重要：**
单 Agent 跑任务和多个 Agent 并行跑是两种工作方式，Orca 的产品形态就是后者：一台机器同时跑几个编码 Agent，各自领 issue、各自出 diff，人负责 review。Stacked PRs 支持补上了团队工作流的关键一环——Agent 生成的多个关联改动可以按依赖关系层层评审合并，而不是堆成一个巨型 PR。43,968 总星、1,235/天的增量说明这个形态有稳定需求。

**讨论现场：**
- v1.4.180 release notes 中 Stacked PRs 功能带 GitHub stack map 和合并流界面，社区反馈主要是"终于不用手动拆 PR 了"。
- 该版本还把 Agent artifact 发布改成默认关闭的能力门（capability gate），安全默认值的设计获好评。

**来源：** https://github.com/stablyai/orca/releases
