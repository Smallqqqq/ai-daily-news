1. archify（Agent 架构图 skill，单日 4,239 星续爆）

影响力 9.3/10 GitHub Trending +4,239 stars/day，总星 23.6K
![archify 架构图 demo](./archify-demo.png)

是什么

tt-a1i 的开源 agent skill（MIT），让 agent 把代码库或系统描述画成交互式技术图：架构、工作流、时序、数据流、生命周期五种图型。Typed JSON 中间表示 + 确定性校验，agent 控制层级、间距、路由、强调，产出自包含 HTML（可导出 PNG/SVG/WebM）。Architecture Delta 模式对 PR 生成 Before/Delta/After 三帧快照，把代码评审的架构差异直接画出来。

怎么用

# 全局安装（Claude Code / Codex / Cursor / OpenCode / Raven）
npx skills add tt-a1i/archify -g
# 免安装试用
npx skills use tt-a1i/archify@archify --agent codex
# 之后直接说："Use archify to map this repository's runtime architecture."

为什么重要

昨天（8/27）单日 +1,035 星、总星 18.1K；今天单日 +4,239 星、总星 23.6K。48 小时进账约 5.5K，增速翻 4 倍。此前让 agent 画图的主流路径是 Mermaid：生成快、布局糙。archify 靠「agent 控制布局 + 类型化交付 + 五重校验不过不发布」把画图变成可复验的工程步骤，节点可链到 Git 固定 commit 做来源证据。它是本周少数靠单点做深、不靠打包合集冒头且持续加速的项目。

讨论现场

  • Trendshift 连续在榜，简介「beautiful, verifiable architecture, workflow, sequence, data-flow, and lifecycle diagrams in a single HTML file」。
  • 社区讨论集中在 Architecture Delta 用于 PR review：以前架构改动靠 git diff 硬读，现在直接看三帧对比图。
  • README 明确与 Mermaid 的分工：Mermaid 适合快速出图，archify 适合「要拿去评审、要存档、要分享」的图。

来源： https://github.com/tt-a1i/archify

2. God's Eye View（浏览器里的「间谍卫星模拟器」，数据是真的）

影响力 8.8/10 GitHub Trending +1,984 stars/day，总星 8.3K
![God's Eye View demo](./gods-eye-view-demo.jpg)

是什么

Bilawal Sidhu（God's Eye View 病毒视频系列作者）开源，MIT。纯浏览器应用：CesiumJS + Google Photorealistic 3D Tiles 渲染真实地球，叠加航班（OpenSky/adsb.lol）、军用 ADS-B、AIS 船只、约 840 颗卫星（SGP4 轨道）、地震（USGS）、火点（NASA FIRMS）、交通（TomTom）、约 800 路公开 CCTV 投影进 3D 城市。无框架 vanilla JS + Vite。内置 OpenAI Realtime 语音 agent，28 个工具：相机控制、标注测距、图层查询、电影化运镜。分享链接会把相机、视觉风格、图层、跟踪目标序列化进 URL。

怎么用

git clone https://github.com/bilawalsidhu/gods-eye-view
cd gods-eye-view
cp .env.example .env   # 只需填 GOOGLE_MAPS_API_KEY
npm install
npm run dev -- --host localhost --port 4173

10 个图层零 key；Google 3D 瓦片每月 1,000 次免费 root-tile 会话（每次最长 3 小时）。

为什么重要

7 种 GLSL 传感器视觉风格（CRT、夜视、热成像 FLIR 等），点击任意飞机/船只/火灾/ISS 即可追踪，支持驾驶舱视角跟飞和 250km 联系名单。此前同类「上帝视角」演示多为闭源或视频拼贴，这是第一个把多源真实公共数据 + 语音 agent 控制开源成可本地跑的项目。8.3K 总星中今天一天进账 1,984。

讨论现场

  • 作者该系列视频在 YouTube 累计 500 万+ 播放，社区最关注数据源全公开、本地可跑两点。
  • README 明示伦理边界：不提供「点名搜索、人脸识别、追踪个人」，这也是社区讨论里反复出现的点。

来源： https://github.com/bilawalsidhu/gods-eye-view

4. ai-memory（跨 vendor 的 agent 长期记忆，Rust 单二进制）

影响力 8.1/10 GitHub Trending +606 stars/day，总星约 5K

是什么

akitaonrails 出品。一个 Rust 二进制跑 MCP/HTTP server，把 Claude Code 会话干到一半的任务换到 Codex 接着干：sanitized 生命周期 hook（prompt、tool call、session 边界）编译成 git 版本化的 markdown wiki，任何支持的 agent 都能查，不需要向量库。数据目录：wiki/（真相源）、raw/（不可变转录段）、db/（SQLite FTS5）、models/、logs/。检索融合 FTS5、实体匹配 RRF、图邻居 RRF、可选向量 RRF。

怎么用

# Arch Linux
yay -S ai-memory-bin
systemctl --user enable --now ai-memory
# 或 Docker（loopback 绑定）
docker run -d --name ai-memory -p 127.0.0.1:49374:49374 akitaonrails/ai-memory:latest
# 装 CLI 后
ai-memory install-mcp && ai-memory install-hooks
# 跨 harness 接续同一工作流
ai-memory run claude     # 然后 ai-memory run codex --yolo 续上

为什么重要

支持 16+ CLI（Claude Code、Codex、Cursor、Gemini CLI、OpenClaw、Antigravity、Kimi Code 等）。session 结束时观察编译成摘要，下一个 agent 的 SessionStart 注入有界 handoff（开放问题 + 下一步）。LLM 可选：零 LLM 模式仍有 FTS5/实体/图检索。走 Karpathy「compile-not-retrieve」路线，相比 agentmemory / basic-memory，差异在于 vendor 中立、单二进制、git 版本化。

讨论现场

7. go-modern-guidelines（JetBrains 官方：教 AI agent 写现代 Go）

影响力 7.3/10 GitHub Trending +300 stars/day，总星 2.1K

是什么

JetBrains 官方仓库，目标读者是 coding agent 而非人。解决两个失败模式：训练数据滞后（模型不知道截止日期后的语言特性）与频率偏差（旧写法在训练语料中占比高，模型惯性输出）。skill 读 go.mod 检测 Go 版本，只用该版本可用的语法与 stdlib，并优先新写法（与 go 的 modernize analyzer 取向一致）。

怎么用

# Claude Code
/plugin marketplace add JetBrains/go-modern-guidelines
# 安装 modern-go-guidelines@goland-claude-marketplace，调用 /modern-go-guidelines:use-modern-go
# Codex
codex plugin marketplace add JetBrains/go-modern-guidelines
codex plugin add modern-go-guidelines@goland-codex-marketplace
# 其他 agent
npx skills add JetBrains/go-modern-guidelines

为什么重要

覆盖 Go 1.0–1.27 特性，示例替换全是具体语法：if-else 取最大值 → max(a,b)，手写循环 → slices.Contains，nil 链判断 → cmp.Or，加 new(42) 指针与 errors.AsType[T](err)（Go 1.26）。2,147 星两天内攒起，是官方下场给 agent 写编码规范的第一个大厂案例。

讨论现场

  • 仓库开篇点出的训练数据滞后与频率偏差两个失败模式被社区转发最多。
  • 兼容 5 种 agent（Junie / Claude Code / Codex / Cursor / OpenCode）；首次安装自动 go install 小 CLI 到本地缓存，不改项目文件。

来源： https://github.com/JetBrains/go-modern-guidelines

8. Qwen3.8-Flash-Next（Qwen4 架构预览：125B 主模型 + 51B N-gram 查表）

影响力 7.2/10 知乎热文（8/27）+ ModelScope 官宣 + SGLang day-0 支持
![Qwen Next demo](./qwen-next-demo.png)

是什么

阿里 Qwen 团队 8/26 晚发布，官方定位 Qwen4 架构预览。125B 主模型 + 51B N-gram Embedding 查表，每 token 仅激活 6B。48 层 = 36 层 Gated DeltaNet（线性注意力）+ 12 层 Qwen Sparse Attention。MoE 512 专家 top-10 路由。N-gram 查表放在第二个 decoder 块：hash 寻址，每 token 取 16 行（8 个 2-gram + 8 个 3-gram head）拼成 2560 维向量；稀疏 pinned-host offload 让表驻留内存，每 token 只搬 16 行进 GPU。

怎么用

# SGLang day-0 支持；NVFP4 量化 RadixArk/Qwen3.8-Flash-Next-NVFP4 同日发布
pip install "sglang[all]"
python -m sglang.launch_server --model RadixArk/Qwen3.8-Flash-Next-NVFP4 --tp 4
# per-workload 配置见 SGLang Cookbook：
# https://docs.sglang.io/cookbook/autoregressive/Qwen/Qwen3.8-Flash-Next

API：千问平台（OpenAI 协议）。本地：llama.cpp/Ollama 量化版已跟进。

为什么重要

B200 上 TP4、NVFP4、batch 1 带 MTP：540 tok/s 解码（accept length 约 3.3）。H200 TP4 带 offload：目标权重每 GPU 83.91 → 60.45 GiB（-23.46 GiB），KV 容量 1.84M → 3.28M token（+78.54%），吞吐几乎不变（-0.07%）。对比 DeepSeek V4 Flash 与 GLM-5.3 Flash，125B/6B-A 是三者中最激进的稀疏比。

讨论现场

  • 知乎 8/27 热文《前沿性能，普惠价格，Qwen3.8-Flash重划模型性价比"斩杀线"》在发布次日跟进。
