## 1. different-ai/openwork — 开源版 Claude Cowork

![[openwork-demo.png]]

**评分: 9.0/10 | 可操作性: 高 | 热度: GitHub 915 stars/day（总 18,793 stars），今日 Trending #2**

**是什么：**
openwork 是 Claude Cowork 的开源替代方案，基于 opencode 构建。Claude Cowork 是 Anthropic 推出的多人 AI 协作编码环境（闭源付费），而 openwork 让团队在自己控制的基础设施上获得类似体验——多人实时共享工作空间、AI agent 辅助编码、终端和文件系统操作。TypeScript 编写，支持自托管部署。

```bash

pnpm dev
```

## 2. huggingface/speech-to-speech — 本地语音 Agent 构建套件

![[speech-to-speech-demo.png]]

**评分: 8.8/10 | 可操作性: 高 | 热度: GitHub 628 stars/day（总 8,954 stars），今日 Trending #3**

**是什么：**
HuggingFace 官方发布的语音到语音 pipeline，用开源模型在本地构建语音对话 agent。不同于调用云端 API（Whisper + GPT + TTS），这套工具将 STT、LLM 推理、TTS 全部本地化——适合对延迟和隐私有要求的场景，比如离线语音助手、实时翻译耳机、车载语音系统。


## 7. Tencent AngelSpec — 投机解码训练框架开源

![[angelspec-demo.png]]

**评分: 7.5/10 | 可操作性: 高 | 热度: 7月30日新发布，torch-native 开源框架**

**是什么：**
腾讯开源的 AngelSpec 是一个 torch-native 的投机解码 draft model 训练框架。覆盖自回归多 token 预测（MTP）和 block-parallel DFlash 系列。核心创新在于将"工作负载异质性"作为一等设计约束——不同业务场景（客服/代码/翻译）的推理流量特征完全不同，AngelSpec 能为每种场景训练专门的 draft model。

**怎么用：**
```bash
git clone https://github.com/Tencent/AngelSpec.git
cd AngelSpec
pip install -e .
# 使用共享参数多深度方案训练 MTP draft model
python train_mtp.py --config configs/mtp_shared_depth.yaml
```

**为什么重要：**
投机解码是目前 LLM 推理加速的主流方案，但 draft model 的质量直接影响加速效果。AngelSpec 的共享参数多深度方案（一个物理 block 复用于多个预测深度）显著降低了 draft model 的训练和推理开销。配合 target-model rollout 训练策略，draft model 能更准确地捕捉目标模型的 token 选择模式。

**讨论现场：**
- NCIJ Network 分析：AngelSpec 的"训练即测试"策略（EAGLE-3 提出的 Training Time Test 原则）让 draft model 在训练时就看到实际推理场景的分布
- 社区关注点：能否与 vLLM/SGLang 等主流推理框架集成

**来源：** https://github.com/Tencent/AngelSpec

## 8. Infisical Agent Proxy — AI Agent 凭证安全代理

![[infisical-agent-proxy.png]]

**评分: 7.5/10 | 可操作性: 高 | 热度: 前身 Agent Vault 2000+ GitHub stars，7月30日正式产品化发布**

**是什么：**
Infisical 于 7 月 30 日推出的 Agent Proxy，让 AI agent 调用外部服务时不需要接触到真实的 API key。Agent 发送请求时使用 dummy 凭证，Agent Proxy 从 Infisical 密钥库中检索真实密钥、注入请求后转发至目标服务。整个过程对 agent 完全透明。

**怎么用：**
```bash
# 注册 Infisical 账号（免费 tier 即可使用）
# 配置 Agent Proxy 端点
export INFISICAL_AGENT_PROXY_URL="https://app.infisical.com/agent-proxy"
# Agent 使用 dummy key 发起请求，Proxy 自动注入真实密钥
curl -H "Authorization: Bearer dummy-key" $INFISICAL_AGENT_PROXY_URL/api/github/repos
```

**为什么重要：**
AI agent 最大的安全隐患之一是"给了 agent 什么权限"。Agent Proxy 让 agent 永远碰不到真实密钥，即使 agent 被 prompt injection 攻击，攻击者也无法窃取凭证。相比传统的"把 API key 放环境变量"，这是更安全的架构。前身 Agent Vault 已积累 2000+ stars、数十万次 agent 运行验证。

**讨论现场：**
- X 上 Infisical 联合创始人 @dangtony98 发帖："Agent Proxy 是无状态的——密钥永远只存在于 Infisical 中，proxy 不存储任何凭证"
- RuntimeWire 分析：Infisical 通过 Agent Proxy 将密钥管理从"人的 DevOps"扩展到"agent 的 DevOps"，这是一个新市场

**来源：** https://runtimewire.com/article/infisical-launches-agent-proxy-ai-agent-api-keys
