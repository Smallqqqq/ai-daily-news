## 1. morluto/rea：单日 +25,793 星，连续三天全站第一（已于 10-09 首次收录）

![[rea-demo.png]]

**评分: 9.4/10 | 可操作性: 高 | 热度: GitHub Trending 全站 #1，+25,793 stars/day（总 74.3k，fork 15.7k）｜YouTube 实机解读 11,965 播放**

**是什么：**
一个 MIT 许可的开源 MCP server，把逆向工程能力装进你的 coding agent：从解包出的 Electron/JavaScript 应用树和 ASAR 归档开始分析，一路向下追到原生二进制与运行时行为。它自己不做反编译，而是编排 Hopper、Ghidra、IDA 等既有引擎，把结果整理成 agent 可消费的结构化证据（evidence、恢复出的调用图、limitations、unknowns 四个字段），支持 Claude Code、Codex、Cursor、Gemini CLI、Grok Build 接入。

**怎么用：**
```bash
# 一键为已安装的 agent 注册 MCP 与技能
npx rea-agents setup

# 零配置试用：分析一个解包后的 JS 应用目录
npx -y rea-agents@latest analyze-javascript-application /path/to/app --json

# 或全局安装
npm install --global rea-agents
rea update
```

**为什么重要：**
官方公开的验证用例：用 agent 重建经典游戏 DX-Ball，通过 3,205 条原始 x86 测试用例，63 个编译函数实现字节级复现。传统流程需要人坐在 Ghidra/IDA 里逐函数标注、写脚本，rea 把入口收敛成一条 npx 命令。仓库累计 2,189 次提交、15.7k fork，是目前 star 数最高的 agent 逆向工程项目。

**讨论现场：**
- Signal Coders（YouTube，11,965 播放）："One npx command now hands your coding agent a decompiler"（一条 npx 命令把反编译器交到编码 agent 手里）
- Medium 每日 GitHub 追踪（10-07）："rea 拿下当日最大涨幅……重复了编码工具'先辅助、再技能、后 agent'的演进路径"，把它列为逆向工程自动化的第三个阶段样本

**来源：** https://github.com/morluto/rea

## 2. Talorys：跑在自己 Cloudflare 账户里的个人 AI agent

![[talorys-demo.png]]

**评分: 9.0/10 | 可操作性: 高 | 热度: HN 首页 257 分 / 123 条评论｜仓库创建于 10-10，当天 410 星**

**是什么：**
单用户的个人 AI 助手，整个应用部署在你自己的 Cloudflare 账户内：聊天、长期记忆、任务、笔记、项目和定时提醒一应俱全，作者不运营任何后端、不收集遥测。技术栈是 React/Pages 前端 + Hono Worker + Durable Object（SQLite 状态），模型走 Workers AI 的 @cf/zai-org/glm-4.7-flash。

**怎么用：**
```bash
npx create-talorys@latest
# 按提示登录自己的 Cloudflare 账户完成部署
# 本地开发：npm run dev（内置 mock AI，无需 Cloudflare 登录）
```

**为什么重要：**
把个人 agent 的托管成本压到零：免费额度即可运行，付费也只需 Workers 最低档；对比自建 VPS 约 $240/年、Mac mini 方案 $649 首年。仓库创建于 10-10，一天内 410 星并冲到 HN 首页 257 分。

**讨论现场：**
- flufluflufluffy 引发最大争论："I define 'self-hosted' as something that I host myself"（我定义的 self-hosted 是我自己拥有硬件），123 条评论里最主要的定义之争由此展开
- scosman 实测性能："Cloudflare worker AI is verrrrry slow for user interactive use cases"（交互式聊天场景下 Workers AI 很慢，更适合后台任务）
- andrewdb 实测缺陷：写下"I am a vegetarian"后提问晚餐建议，模型仍推荐鸡肉和三文鱼，已提 issue 建议加语义检索

**来源：** https://github.com/rociiu/talorys ｜ https://news.ycombinator.com/item?id=50031614

## 6. Microsoft Execution Containers (Mxc) 1.0.0：给 agent 生成的代码上 OS 级沙箱

**评分: 7.9/10 | 可操作性: 中 | 热度: HN 首页 161 分 / 38 条评论**

**是什么：**
微软正式发布的策略驱动执行层，专门隔离 AI agent 动态生成的不可信代码：边界由操作系统强制（文件、网络等资源访问策略），而不是靠提示词约束。提供 Enforcement、Learning、Permissive 三档模式；容器后端包括跨平台进程容器（Win11/macOS/Linux）、Win11 会话容器与 WSLc、实验性 MicroVM。已集成 GitHub Copilot、OpenClaw、OpenAI Codex、Replit。

**怎么用：**
```bash
# SDK 已发布到 npm / NuGet / crates.io（Node、.NET、Rust），仓库内含 JSON 策略 schema、文档与示例
git clone https://github.com/microsoft/mxc
cd mxc && cat README.md
```

**为什么重要：**
agent 安全最大的缺口是"全放开有风险、全封锁没效率"，Mxc 把权限收敛做成 OS 原语，同一份策略可跨 Windows/Linux/macOS 三种后端执行。这是 HN 当日首页开发者安全话题里分数最高的条目。

**讨论现场：**
- 微软官方博客（作者 Logan Iyer）对定位的原文表述集中在"策略驱动的包含（containment）"，即解决不可信代码"全放开有风险、全封锁失效率"的两难

**来源：** https://blogs.windows.com/windowsdeveloper/2026/10/07/microsoft-execution-containers-policy-driven-containment-for-ai-agents/ ｜ https://github.com/microsoft/mxc

## 10. TokenRouter：token 级 LLM 路由的服务系统（NeurIPS 2026）

**评分: 7.4/10 | 可操作性: 中 | 热度: HF Papers 当日第 3（126 赞），NeurIPS 2026 接收**

**是什么：**
token 级 LLM 路由能同时提升效率与输出质量，但现有服务系统都建立在单模型假设上，会出现 step desynchronization（步调失同步）与批次准入延迟。TokenRouter 采用 "request-centric programming, model-centric execution"：为每个模型启动子服务器异步派发，调度器用延迟批处理，超参由吞吐模型推导。

**怎么用：**
```bash
git clone https://github.com/thu-nics/TokenRouter
```
论文：https://arxiv.org/abs/2610.12242

**为什么重要：**
跨多种路由算法、负载与模型组合，解码吞吐比现有系统高 2.01 到 64.15 倍。对做多模型路由（FastRouter、OpenRouter 这类场景）的团队，这是把路由从算法层做到服务系统层的参考实现。

**讨论现场：**
- HF Papers 当日榜第 3 位（126 赞），是当日榜单上唯一的路由服务系统类工作

**来源：** https://arxiv.org/abs/2610.12242 ｜ https://github.com/thu-nics/TokenRouter
