## 1. diagram-design（Claude Code 图表技能包）

![[diagram-design-demo.png]]

**评分: 9.5/10 | 可操作性: 高 | 热度: GitHub Trending 总榜 #1，单日 +4,475 stars**

**是什么：**
Cathryn Lavery（BestSelf.co 创始人）发布的 Claude Code 技能，覆盖 29 种 editorial 风格图表：架构图、时序图、泳道图、甘特图、象限图、维恩图、数据流图等。Agent 按自然语言描述自动选型，生成自包含的 HTML+SVG 文件，不依赖 Mermaid 或外部渲染服务。定位语是 "Editorial diagrams your designer won't hate"，专门解决 AI 生成的图表太丑、没法放进文档的问题。它还支持导入 draw.io / Mermaid 源文件重绘，并从目标网站自动提取配色与字体做品牌化。

**怎么用：**
```bash
# Claude Code 内安装（第三方 marketplace 需在 /plugin 中手动开启）
/plugin marketplace add cathrynlavery/diagram-design
/plugin install diagram-design@diagram-design

# 导出为 PNG/SVG（PNG 需要 Playwright）
/diagram-design:export path/to/diagram.html --svg-only --png-only --scale=3

# 导入 draw.io / Mermaid 重绘
/diagram-design:import platform.drawio --size=slide-16x9 --detail=simplified --audience=executive
/diagram-design:import-mermaid architecture.mmd
```

**为什么重要：**
单日 4,475 stars，GitHub Trending 全站第一，总星 14,777（单日涨幅约 30%）。相比手写 Mermaid 语法和 draw.io 拖拽，它把「出图」变成 agent 工作流里的一句话，PNG/SVG/HTML 三种格式都走同一个技能。4 个调节旋钮（Format/Size/Detail/Audience）让同一张图可以同时面向工程师和汇报对象。

**讨论现场：**
- X 上每日 GitHub trending 播报 @alexchen77sh 将这条置顶：「↑ #1 cathrynlavery/diagram-design」，配文称 Agent 竞争正从「谁会聊天」转向「谁能执行更久、用专业工具」。
- 仓库 README 评论区集中在两种用法：Claude Code 插件市场安装，以及 clone 后 symlink 到 `~/.claude/skills/` 的手动方式。

**来源：** https://github.com/cathrynlavery/diagram-design

## 2. DeepSeek Harness（DeepSeek 开源 agent 框架）

![[deepseek-harness-demo.png]]

**评分: 9.0/10 | 可操作性: 高 | 热度: HN 563 points / 246 comments（8-14 首页）**

**是什么：**
DeepSeek 官方开源的 agent harness 框架，处于 developer preview，MIT 协议。底层是 Cordis 内核，模型、工具、skills、session、sandbox、存储、循环、调度、UI 全部实现为可替换插件。所有输入输出走 append-only session log：prompt、推理、工具调用结果、子 agent 调度、上下文注入全部留痕，可在 Trajectory 视图里重放、fork、搜索。提供 Standard（完整编码 agent）、Code（模型写 TypeScript 程序编排多步操作）、Minimal（仅 bash + str_replace_editor，用于 benchmark）、Creator（运行时插件热测）四种模式。

**怎么用：**
```bash
# 需要 Node.js，一条命令起 Web 界面
npx @deepseek-ai/dsh web

# 或从源码跑
git clone https://github.com/deepseek-ai/deepseek-harness
cd deepseek-harness && npm install && npm start
```

**为什么重要：**
OpenAI Codex、Anthropic Claude Code 的 agent 运行时全是闭源的，DeepSeek Harness 是一线大厂里第一个把完整 agent harness 开源的。插件化架构意味着模型供应商、工具集、存储层都能换，`dsh-plugin` topic 下已有社区插件生态。HN 上 563 points 是当日首页仅次于 Gemini 3.7 Flash 的讨论量。

## 3. NVIDIA-NeMo Switchyard（LLM 模型路由层）

**评分: 8.5/10 | 可操作性: 高 | 热度: GitHub 单日 +408 stars，总星 3 天破 1.2k**

**是什么：**
NVIDIA NeMo 团队用 Rust 写的 LLM 流量路由层，与 8-11 发布的 Nemotron Lightning（NVIDIA 首个开源模型）同日推出。客户端以原生 OpenAI Chat Completions / Responses / Anthropic Messages 格式接入，Switchyard 负责选后端、按后端原生格式转发、再把响应翻译回客户端格式。路由策略有 LLM Classifier、Stage Router、Escalation Router（小模型答不了自动升级到大模型）、Random、passthrough。后端支持 vLLM、NVIDIA NIM、Ollama 及任意 OpenAI 兼容端点，可直接接在 Claude Code、Codex CLI、OpenClaw 前面。

**怎么用：**
```bash
# CLI（需要 Python 3.10）
uv tool install --python 3.10 "nemo-switchyard[cli]"

# 独立 server 模式
cargo install --locked switchyard-server
export OPENROUTER_API_KEY=sk-xxx
switchyard-server --config routes.toml --dry-run
switchyard-server --config routes.toml --host 127.0.0.1 --port 4000
```

**为什么重要：**
单日 408 stars。它的价值在于「不改一行客户端代码」就能做模型 A/B 测试、成本优化和故障降级——Claude Code 这类写死 API 格式的工具，现在可以把便宜模型路由给简单任务、强模型路由给复杂任务。routes.toml 里 `mode = "escalation"` 一行就能配置升级链路。知乎专栏「英伟达造万亿参数模型」称它为「简单任务交给速度快、价格低的小模型，复杂规划交给大模型的免费路由工具」。

**讨论现场：**
- GitHub 仓库 3 天 226 commits、40 issues、47 PRs，README 内置 benchmark/ 目录用于 A/B 测试和成本实验。
- 知乎「英伟达造万亿参数模型，为整座AI工厂促销」一文将 Switchyard 定位为「简单任务交给速度快、价格低的小模型，复杂规划交给大模型的免费路由工具」。

**来源：** https://github.com/NVIDIA-NeMo/Switchyard

## 4. cactus-compute/needle（14MB 端侧工具调用模型）

![[needle-demo.png]]

**评分: 8.5/10 | 可操作性: 高 | 热度: GitHub 单日 +769 stars，总星 4,989**

**是什么：**
45M 参数的开放模型，专做工具调用、设备使用和结构化提取。整个模型经 CQ2-bit 量化编译成单个 14MB 引擎二进制（权重直接烘焙进引擎，无独立权重文件），跑完整会话约 28MB 内存。架构叫 Simple Attention Network：Hadamard MLP 替代 FFN、GQA 注意力、engram 键值记忆、多通道超连接，还有 256-token 滑动窗口 + 工具作为 KV sinks 固定的有界内存设计。目标设备是手机、可穿戴、智能家居和机器人。

**怎么用：**
```bash
pip install cactus-needle
# NVIDIA GPU 训练加 [gpu]，Apple Silicon 加 [metal]

# 工具调用：@needle.tool 装饰器，签名即参数 schema
python - <<'EOF'
import needle
@needle.tool
def get_weather(city: str) -> str:
    """Get current weather for a city."""
    return "28°C, sunny"
agent = needle.Needle(tools=[get_weather])
print(agent.run("what's it like in Lagos right now?")["results"])
EOF

# 浏览器 playground 与微调
needle playground                       # http://127.0.0.1:7860
needle finetune data.jsonl --epochs 10  # LoRA 微调
needle build checkpoints/needle2.pkl --lora checkpoints/needle_lora.pkl --out my_needle.cact
```

**为什么重要：**
单日 769 stars。README 自述在工具调用 benchmark 上与 FunctionGemma 270M、LFM2.5 230M、Apple FM 等小模型互有胜负，体积小 5 到 70 倍（2-bit 对比对方 f16）。对比同样主打端侧的 Gemma 3 270M（HF 下载几百 MB），needle 一个 14MB 文件内嵌全部权重，`pip install` 完就能在树莓派级别的设备上跑带工具调用的完整 agent 循环。

**讨论现场：**
- X 上 @alexchen77sh 的 trending 播报将 needle 列为当日信号之一：「Open-source AI is moving beyond generate an answer toward native deliverables, shared team memory, and models that can run at the edge」。
- README 直接列出对比对象（FunctionGemma 270M、LFM2.5 230M、Apple FM），并把有界内存机制（256-token 滑动窗口 + 工具作 KV sinks）写成设计章节。

**来源：** https://github.com/cactus-compute/needle
