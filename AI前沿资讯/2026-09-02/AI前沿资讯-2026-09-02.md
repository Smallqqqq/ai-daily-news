## 1. Claude Fable 5.1 / Mythos 5.1 — Anthropic 新一代旗舰发布

**评分: 9.5/10 | 可操作性: 高 | 热度: HN 957 points / 893 comments，Google 官方推文下都被刷"Fable 5.1 is out"**

**是什么：**
Anthropic 于 9 月 1 日发布 Claude Fable 5.1（公开可用）与 Claude Mythos 5.1（受限访问）。Fable 5.1 面向编码、知识工作和长时程 agent 任务，1M token 上下文。同一天 Claude Code 2.1.257 发布，默认 Fable 模型切换为 5.1；Auto 模式同步收紧，不再自动批准云元数据凭据抓取、出口规避、跨租户访问这三类操作。

**怎么用：**
```bash
# Claude Code 更新后 Fable 5.1 即默认 Fable 模型
claude update

# 通过 API 调用（缓存读取 $0.25/M tokens，1M 上下文）
# 模型 ID 与调用方式见官方文档：
# https://platform.claude.com/docs/en/models/fable-5-1/whats-new
```

**为什么重要：**
Terminal-Bench 4.0 得 55.8%，前代 Fable 5 为 42.0%，提升 13.8 个百分点；Anthropic 员工在 HN 确认 Terminal-Bench-Science 分数较 Fable 5 翻倍以上。缓存读取价格降至 $0.25/M tokens，降幅 75%——长 agent 任务里缓存读取是大头，这项降价直接改变成本模型。

**讨论现场：**
- HN（957 pts）：Anthropic 员工 felixrieseberg 称写作风格明显改善，"更少 Claude 味"，并预告科学领域将迎来类似数学的突破
- HN：satvikpendem 提醒，"思考摘要"并非真实思维链——出于防蒸馏考虑真正的思考被禁用，无法据此推断模型实际在想什么
- HN：Anon1096 解释"Claude 味"来自后训练（RLHF）而非预训练语料；tkgally 给出对策：让 Claude 写一个强制清晰写作的 skill 放进 CLAUDE.md，实测后续报告质量大幅提升

## 2. archify — 让 Agent 把系统描述画成可验证的交互式架构图

**评分: 9.0/10 | 可操作性: 极高 | 热度: GitHub Trending 当日全站增速第一，单日 +4,562 星（总 41K）**

**是什么：**
tt-a1i 开发的 agent skill（MIT 许可，v2.16.0）。Agent 把代码库或系统描述转成 typed JSON IR，archify 用 Node.js 渲染器确定性地编译成自包含 HTML/SVG——架构、工作流、序列、数据流、生命周期五类图，带动效、深/浅主题和 before/delta/after 三视图对比。支持 Cursor、Claude Code、Codex CLI、OpenCode、Raven、DeepSeek Harness。官方站点 tt-a1i.github.io/archify。

**怎么用：**
```bash
# 全局安装（Cursor / Claude Code / Codex / OpenCode 通用）
npx skills add tt-a1i/archify -g

# 或临时用 Codex 跑一次
npx skills use tt-a1i/archify@archify --agent codex
```
然后在对话里直接说："画出 Browser → API → Redis → PostgreSQL 的缓存未命中路径序列图。"

**为什么重要：**
单日 +4,562 星是当日 GitHub 全站最高增速（linkly 统计 09-01 也有 +3,813 星）。区别于 Mermaid 这类纯文本转图工具：JSON IR 加确定性校验意味着 agent 生成的图能被验证，节点可溯源到 git commit，导出的 PNG/SVG/WebM 能直接进文档和 PR 评审。这正是 2026 年 agent 产物从"看起来对"到"能进工作流"的分界线。

**讨论现场：**
- coddykit 评测称其为 "the most important agent skill of 2026"，60 秒内从描述到成图
- EverMind 的 Raven harness、APINEBULA 已列为官方赞助商，skill 生态开始出现商业支撑

**来源：** https://github.com/tt-a1i/archify

## 3. DeepSeek-V4-Flash-Vision-Exp — 305B 多模态权重 MIT 开源

**评分: 9.0/10 | 可操作性: 高 | 热度: r/LocalLLaMA 热议，Fireship 视频引爆，Bluesky 多位 AI 专家转发**

**是什么：**
DeepSeek 把 V4 家族第一个多模态模型的权重放上了 Hugging Face：304.6B 参数（48 个 safetensors 分片，约 168GB），MIT 许可。模型在 V4-Flash 架构上增加视觉编码器和对齐模块继续训练，仓库同时附了编码参考实现和最小 PyTorch 推理代码、vLLM/SGLang 部署命令。API 自 8 月 21 日开放，权重 10 天后落地，无论文、无发布会，纯代码交付。

**怎么用：**
```bash
# 下载权重
hf download deepseek-ai/DeepSeek-V4-Flash-Vision-Exp --local-dir ./V4-Flash-Vision

# vLLM 部署（README 内置命令）
vllm serve deepseek-ai/DeepSeek-V4-Flash-Vision-Exp

# 或者直接用 API：与 DeepSeek-V4-Flash 同价，多模态推理不涨价
```

**为什么重要：**
多模态 agent 基准 ApexBench Pass@1 得 36.5，纯文本版 V4-Flash 只有 26.2，逼近 Opus-4.8 的 39.4；Terminal Bench 2.1 得 83.9（Opus-4.8 为 85.0）；七个文本基准里六个超过 V4-Flash。每张图仅消耗 384 token，单次最多 600 图。以 V4-Flash 的 API 价格拿到接近 Opus 4.8 的多模态 agent 能力，这是 9 月开源圈最硬的性价比事件。

**讨论现场：**
- r/LocalLLaMA："MIT license too, super efficient weights+kv cache which can run on 192GB"——社区关注点从能不能下转到多大显存能跑
- Bluesky @timkellogg：加了视觉编码器的 V4-Flash 在大多数基准上比纯文本版更强，属于加量不加价

**来源：** https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-Vision-Exp
