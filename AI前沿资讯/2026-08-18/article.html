1. Strix（usestrix/strix，开源 AI 渗透测试工具）

![Strix 演示](./strix-demo.png)
影响力 8.9/10 GitHub Trending 今日 #3，598 stars/day，总 53,055★

是什么：

0xallam 开发的 Apache-2.0 开源 AI 渗透测试工具，2025 年 8 月创建。它把多 agent 编排成一支黑客小队：动态运行你的代码、找漏洞、再用真实 PoC 验证，不像传统静态扫描器那样报一堆误报。新变化：Strix 已集成 GitHub Actions，每个 PR 自动扫描，不安全的代码在进生产前被拦下。

怎么用：

# 安装（首次运行会自动拉取沙箱 Docker 镜像）
curl -sSL https://strix.ai/install | bash

# 配置任意一家 LLM（OpenAI/Anthropic/Google 等）
export STRIX_LLM="openai/gpt-5.4"
export LLM_API_KEY="your-api-key"

# 对本地代码目录发起一次安全评估
strix --target ./app-directory

为什么重要：

598 stars/day 排今天 GitHub 全站第三，总星从 7 月的约 42K 涨到 53K，一个月 +11K。它和 SAST 工具的核心差别是"验证"：跑真实 PoC 证明漏洞可利用，并直接给出补丁和合规报告。适合 bug bounty 自动化和 CI/CD 左移安全。

讨论现场：

  • X 上 AI 趋势号 @alexchen77sh 总结 8-17 热榜时写道："Agent infrastructure is turning into an ecosystem: runtime, plugins, desktop interfaces, model routing, and structured context are accelerating together." 安全 agent 正是这波生态的一环。
  • GitHub Trending 描述："Autonomous AI hackers that find and fix your app's vulnerabilities"，官网注册即可接入 CI 无需自部署。

来源： https://github.com/usestrix/strix

2. ModLens（liustack/modlens，DeepSeek Harness 视觉插件）

![ModLens 演示](./modlens-demo.jpg)
影响力 8.5/10 今日 +535★，总 1,898★，github.hot 榜单 #6

是什么：

第一个 DeepSeek Harness（dsh）视觉插件，MIT 协议，作者 liustack。DeepSeek 和 GLM 的旗舰模型是纯文本的，读不了图；ModLens 让它们在聊天框里直接粘贴图片，通过原生 modlens_read_image 工具把图片转成结构化 JSON 证据（OCR、版面、语义）。插件会自动发现所有承载 DeepSeek/GLM 纯文本模型的路由，生成 DeepSeek-V4-Flash (modlens vision) 这样的包装入口，视觉模型的原生粘贴不受影响。

怎么用：

# 一条命令安装（版本号显式指定，避开 pnpm 对 24h 内新版本的限制）
npx -y @deepseek-ai/dsh plugin --profile web add @liustack/modlens@3.16.7
# 然后在 dsh 里直接粘贴图片，或选 (modlens vision) 模型入口

为什么重要：

不用换模型就给纯文本模型装上眼睛。+535★/day 的增速说明 dsh 插件生态的需求正在爆发，它与 8-16 首录的热榜 #1 元框架 cordis 属于同一生态（dsh 底层由 cordis 驱动），视觉补上后纯文本模型的可用场景大幅拓宽。

讨论现场：

  • github.hot 榜单描述："全网最强 DeepSeek Harness 外挂视觉插件，为 DeepSeek、GLM 等纯文本模型外挂视觉能力，粘贴图片即得结构化 JSON 证据。"
  • 作者在 README 中特意解释为何不用 @latest 标签安装：pnpm 11 会扣留 24 小时内新发布的版本，导致装到昨天的旧包。这类细节说明插件已经过了真实用户的踩坑期。

来源： https://github.com/liustack/modlens
