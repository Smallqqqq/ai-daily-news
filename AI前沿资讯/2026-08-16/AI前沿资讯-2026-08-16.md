## 2. citrolabs/ego-lite（AI agent 专用浏览器）

![[ego-lite-demo.png]]

**评分: 9.0/10 | 可操作性: 高 | 热度: GitHub Trending 545 stars/day · 总星 11.0k**

**是什么：**
citrolabs 做的浏览器，专供 AI agent 跑浏览器自动化，核心设计是"人和 agent 共用同一个浏览器"：agent 在独立 Space 里执行任务，不打扰你的标签页，同时通过 `ego-browser` 技能访问你真实的登录态、cookie 和书签。能力以 JavaScript 函数暴露给 agent（snapshot、fill、click、wait、navigate、capture），agent 直接写代码组合多步任务。支持 Codex、Claude Code、Cursor 及自定义 agent CLI，当前仅 macOS，Windows/Linux 在路线图上。

**怎么用：**
```bash
# 下载 macOS 应用（Apple Silicon / Intel dmg）
# https://github.com/citrolabs/ego-lite 首页 Download 按钮

# 一条命令给 agent 装技能（首次跑任务时引导安装应用）
npx skills add citrolabs/ego-lite

# Claude Code / Codex 中：
# /ego-browser follow @ego_agent on x.com for me
```

**为什么重要：**
官方基准里对 Vercel agent-browser 完成四项复杂任务，速度提升最高 2.5 倍，token 消耗显著降低。README 对比表覆盖 Browser-Use、agent-browser、ChatGPT Atlas、Perplexity Comet，并行多任务、可复用技能、继承 Chrome 登录数据、同浏览器隔离工作区是它独有的。登录态共享解决 agent 浏览器的头号痛点：此前方案要么重登账号（多数站触发风控），要么把人类挤出浏览器。总星 11.0k 中 545 是今天一天涨的。

**讨论现场：**
- README 定位语："The fastest browser for AI agents to run browser automation, built for sharing your logged-in browser state with your AI agents, like Codex or Claude Code, without disturbing you. Zero cost, zero config."
- 路线图中的"经验积累"功能预告：把成功操作沉淀为可复用工具，类似任务最快提速 5 倍。

**来源：** https://github.com/citrolabs/ego-lite

## 7. MakazhanAlpamys/Soup（一个 YAML 微调 LLM，4GB 显存训 8B）

![[soup-demo.png]]

**评分: 8.0/10 | 可操作性: 高 | 热度: GitHub Trending 297 stars/day · 总星 1.7k**

**是什么：**
Soup 是 LLM 微调 CLI，口号 "Fine-tune and post-train LLMs in one command"：一份 `soup.yaml` 配置 + `soup train` 完成微调。招牌特性是 layer streaming（BETA）：冻结的基座模型按 decoder 层从主机 RAM/NVMe 逐层送入 GPU，只有 adapter 常驻显存，从而在 4GB 笔记本 GPU 上微调 8B 模型。实测 Llama-3.1-8B + NF4 量化达到 119.6 tok/s、峰值显存 3.32GB（RTX 3050 Laptop），结果与模型常驻内存的普通运行 bit-exact 一致。支持 SFT、DPO/ORPO/SimPO/KTO、工具调用，内置 100+ 即用配方。

**怎么用：**
```bash
pip install "soup-cli[train]"
soup init --template chat      # 生成 soup.yaml
soup train                     # 一条命令开始微调
# 关键配置：quantization: 4bit（NF4）、stream_layers: true
soup recipes list              # 查看内置 100+ 模型配方
```

**为什么重要：**
显存门槛的量化对比：传统 QLoRA 微调 8B 模型需要约 8GB 显存，Soup 的 layer streaming 把同一任务压到 3.32GB 峰值，4GB 的 RTX 3050 Laptop 即可跑，结果 bit-exact。对没有高端卡的开发者，这是"在笔记本上做 8B 微调"为数不多的可行路径。297 stars/day 的增速说明低显存微调是真实痛点，配套论文挂在 Zenodo。

**讨论现场：**
- README 强调 4GB 显存笔记本 + NF4 的实测数据（119.6 tok/s、3.32GB 峰值），并注明与常驻内存方案结果一致，堵住"省显存但掉精度"的质疑。
- 内置配方覆盖 Llama 3.x/4、Qwen 2.5/3、Gemma 3、Mistral、DeepSeek、Phi-4 等主流开源模型。

**来源：** https://github.com/MakazhanAlpamys/Soup

## 10. Inferock Bench（LLM API 计费的独立收据，PH 当日第一）

**评分: 7.0/10 | 可操作性: 中 | 热度: Product Hunt 8-15 Launch of the Day #1**

**是什么：**
Inferock Bench 是一个本地代理，坐在你的应用和 OpenAI、Anthropic、Gemini、OpenRouter 之间，捕获每次调用的 token 用量、失败和重试，生成"独立收据"：显示供应商实际收了你多少钱、你多付了多少。定位语 "An independent receipt for every LLM API call"。8-15 登上 Product Hunt 当日第一。

**怎么用：**
```bash
# 官网下载本地代理（inferock 提供安装包），启动后把应用的 base_url 指向本地端口
# OpenAI 客户端示例：
# client = OpenAI(base_url="http://localhost:8787/v1", api_key="local")
```

**为什么重要：**
LLM API 计费此前只能信供应商账单：token 计数规则不透明、重试是否重复计费、缓存命中是否按声称的价格算，全都黑箱。Inferock 把这些问题变成本地可审计的数据。PH 356 followers、当日 #1 说明"计费信任"是真实需求，尤其在峰谷定价（DeepSeek）、effort 分级定价（Anthropic）陆续出现之后，独立计费工具的需求只会更多。

**讨论现场：**
- PH 简介原文："It captures per-call token usage, failures, and retries, then generates an independent receipt showing what you were billed and how much you're actually overpaying for."
- 发布时机被社区注意到：DeepSeek 峰谷定价 8-16 生效当天，这类审计工具的关注度上升。

**来源：** https://www.producthunt.com/products/inferock-bench
