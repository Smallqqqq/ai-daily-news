## 1. Meta Muse Spark Open：816B 旗舰开源，两台 Mac Studio 就能本地跑

![[muse-spark-open-demo.webp]]

**评分: 9.0/10 | 可操作性: 中高 | 热度: HN 629 分 / 360 评论（首页第一）+ TechCrunch / Reuters / 9to5Mac / MacRumors / Engadget / CNBC 全媒体报道**

**是什么：**
Meta Superintelligence Labs 昨天（10-15）放出 Muse Spark 的开放权重版 Muse Spark Open，自称"美国最强的开放权重模型"。MoE 架构，816B 总参数 / 42B 激活，1M token 上下文，原生多模态（文本 + 图像 + 视频 + 音频输入，文本输出），基座带 Perception Encoder，训练数据覆盖 100+ 语言。权重以 Muse Model License 发布，限定商用条款比 Llama 系更保守。

**怎么用：**
```bash
# 下载权重（BF16 / NVFP4 两种检查点在 HF）
huggingface-cli download meta-models/Muse-Spark-Open-816B-A42B

# 推理框架官方支持：vLLM / SGLang / TensorRT-LLM / Transformers / MLX
vllm serve meta-models/Muse-Spark-Open-816B-A42B --tensor-parallel-size 8

# 不想自建：Baseten / Fireworks / Groq / Modal / Nebius / OpenRouter / Together AI 七家托管
# Mac 本地：两台 M5 Ultra Mac Studio（各 512GB 统一内存）+ 最新 MLX
```

**为什么重要：**
这是第一个把"桌面级本地推理"作为发布卖点的旗舰开源模型：两台 M5 Ultra Mac Studio 合计约 1TB 统一内存、1.2TB/s 带宽，Meta 说"两台 Mac Studio 表现得像一台超级计算机"。官方演示用 Muse Code 驱动模型给开源 Mastodon 客户端 Ice Cubes 提交真实 iOS 改动、逐帧操作 DaVinci Resolve 裁竖屏视频。SGLang 的 Helion GPU 内核在 NVIDIA/AMD 上带来 1.03–3.95× 内核级加速。代价也真实：Engadget 算过，四台 256GB Mac Studio 方案约 $38,000。

**讨论现场：**
- HN 用户 isityettime 反对把它叫开源："Still not an open-source license." — 缺少自由软件定义中对使用领域不加限制的 freedom 0，批评把 "open weight" 和开源混为一谈
- HN 用户 seizethecheese 逐条读了许可：宽松，唯一的硬条款是以 MaaS 形式对外提供且 12 个月收入超过两千万美元时须与 Meta 单独签约
- HN 用户 a11r 引用 Artificial Analysis 数据：不及 Qwen3.8 Flash Next 和 GLM 5.3 Flash，而后两者单张 B300 即可运行，"美国开放权重还需要追赶"

## 7. xerj：给 AI 装一条索引搜索通道，比 grep 省 40 倍 token

**评分: 7.6/10 | 可操作性: 高 | 热度: GitHub Trending 单日 +715 星（总 5,742 星，Rust，Apache-2.0）**

**是什么：**
xerj 用 Rust 写的 AI 数据搜索层："autoindex" 能力让 agent 无需 grep 和 sed 的 token 浪费就能知道你的数据。一条命令把代码、文档、日志、PDF 建成索引，服务搜索、RAG、安全审计和 agent 记忆，兼容 Elasticsearch 协议，现有 ES 客户端直接可用。

**怎么用：**
```bash
# 安装
curl -fsSL https://xerj.org/get | sh
# 或 Windows PowerShell 方式见仓库 README
# 然后对目标目录建索引，agent 通过索引检索而不是全文 grep
```

**为什么重要：**
压缩的是 agent 工作流里最贵的隐性成本：grep 一大段代码返回给模型的 token。xerj 给的两个数字——比 grep 少 40 倍 token、reference coding 场景少 2.7 倍——都是可以对照账单的。Elasticsearch 兼容意味着不用改现有查询代码，这是它对已建 ES 基建的团队最大的迁移友好度。

**讨论现场：**
- GitHub Trending 单日 +715 星，在清一色 agent 技能项目里是少见的"基础设施层"条目；trendshift 也把它列入当日新晉（仓库 6 月建，最近一周才爆发）
- README badge 自报 "reference coding: 2.7× fewer tokens"

**来源：** https://github.com/xerj-org/xerj

## 10. Neural Networks Are Already Clean：Goodfire 扔出可解释性重磅文章

![[neural-clean-demo.png]]

**评分: 7.3/10 | 可操作性: 中 | 热度: HN 518 分 / 201 评论，全天讨论热点**

**是什么：**
Goodfire 的 Nick Cammarata 发布长篇互动研究文章（附交互式 neuron microscope），主张：大模型里的"多义神经元"（polysemanticity）根本不是叠加（superposition）造成的，而是架构缺陷、工具太弱、模型太小的产物。真正的机制叫 recursive generalization——神经元像树枝一样长出相关的相邻含义。文章认为网络本身就有可读的构件，不需要先训稀疏自编码器去"解卷"。

**怎么用：**
```bash
# 在线阅读（65 分钟量级）+ 交互显微镜，可定位到具体层和单个神经元
start https://already-clean.goodfire.com/
# 微观镜直达：microscope/large.html?layer=<层>&neuron=<编号>
```

**为什么重要：**
