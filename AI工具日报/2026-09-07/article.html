InsForge — 12.9K stars，把后端变成 MCP 的 agent-native 平台

![insforge-demo](./insforge-demo.png)

编码 Agent 现在能写代码、跑测试、开 PR，一碰后端就卡壳：数据库表要人建、存储桶要人配、函数要人部署。InsForge 把这一步直接收进 Agent 手里——它是一整套 agent-native 后端（Postgres、认证、S3 存储、边缘函数、模型网关、实时订阅、Stripe 支付、托管），全部通过一个 MCP server 和 CLI 暴露给 Agent 调用，编码 Agent 自称后端工程师的短板就这样被填上了。

原理上像 Supabase 换了个视角：把给人用的控制台，换成给 Agent 用的 API。CLI 创建项目时（npx @insforge/cli create）会自动给支持的编码代理装上官方 agent skills。MCP 的 fetch-docs、list-tables、list-functions 这类工具把后端真实状态（schema、函数、存储桶、日志）喂给 Agent，决策基于事实而不是猜。官方还做了数据库分支和可逆写入，Agent 改表可以安全试错。

典型场景：跟 Agent 说“给我起一个带登录和文件上传的 app”，它自己建 auth、建表、开存储桶，你连控制台都不用打开。数据侧：12.9K stars、1.2K forks，YC 2026 春季班（$4M pre-seed），上线当天拿过 Product Hunt #1；官方 MCPMark 基准里对比 Supabase MCP 是 1.6 倍速度、省约 30% token（Claude Sonnet 4.5 下 47.6% vs 28.6% 的 Pass 率）。

Magnitude — 本地模型推理服务器，Agent 不再盲猜

![magnitude-demo](./magnitude-demo.png)

给 Agent 接本地模型的痛点在于选型：机器能跑什么模型、什么量化档位、上下文开多大，Ollama 把选择甩给你自己猜。Magnitude 先给硬件画像（芯片、内存、带宽），据此推荐模型和量化档并给出预估 tok/s，再自动下载、调优、运行，模型按需加载，空闲或内存紧张自动卸载。

技术侧是 Rust 写的专用推理引擎，带投机解码（speculative decoding）和并发调优。对外暴露 OpenAI 兼容（/inference/v1）和 Anthropic 兼容（/inference/anthropic）双端点，跑在 127.0.0.1:10100——现有 agent（Claude Code、Codex、OpenClaw、Cline 等）不用改配置，安装时它直接写好 harness 配置。全离线，没有 API key，没有 token 计费。

典型场景：magnitude setup 交互走一遍，Agent 接着就用本地模型干活；装了 CLI 之后再跑 magnitude docs onboarding，让 Agent 自己读文档完成配置。本周它刚爆发：单周涨了 1.9K stars 到 3.7K。

npm i -g @magnitudedev/cli
magnitude setup

中国专利 skill — 把研发的专利发明人一栏写上名字

![patent-demo](./patent-demo.jpg)

做了多年核心研发，专利发明人一栏从没写过自己的名字——这是多数研发的现实。这个技能包拆成 6 个子技能，覆盖专利全流程：交底书（发明/实用/外观分模板成文+查新）、申请文件（权利要求书/说明书/摘要/附图）、读专利（公开号或 PDF 转通俗笔记连入库 Obsidian 图库）、审查答复（案例分析+向量检索）、著录检索（按发明人/申请人/分类号查国知局）、政策简报（政策雷达）。

比较能打的是技术部分：从产品图/结构图/CAD 提取线稿并标部件序号引出线（外观和实用新型附图的关键），mermaid 流程图直接渲染进 Word 交底书，国知局检索脚本落盘到 outputs/patent-search/。依赖是 Python 3.9+ 加 Playwright，浏览器就绪探测一条命令验证。

pip install -r requirements.txt
