Headroom — 在 agent 和模型之间垫一层压缩，57% 的排障 token 省在原地

![Headroom 压缩管线演示](./headroom-demo.gif)

Agent 的上下文账单总是越滚越大：工具输出接得越多，日志、JSON、文件、RAG 片段越是一股脑进窗口。常见解法要么是换更便宜的模型，要么是人肉裁剪 prompt。Headroom 走第三条路：在 agent 和 LLM 之间加一层本地压缩，内容先过一遍再发给模型，压缩全程在这台机器上跑，原文不出网。

处理管线分三段。ContentRouter 先识别内容类型再挑压缩器：JSON 走 SmartCrusher，源码走基于 AST 的 CodeCompressor，散文和 RAG 文本走 Kompress-v2-base 文本模型（权重开在 HuggingFace）。CacheAligner 负责标记那些会打爆供应商 KV-cache 前缀的易变内容，只标记不改写，保证前缀缓存还能命中。压缩之后原文不丢：CCR 把原始内容缓存在本地，模型需要细节时调 headroom_retrieve 按需取回。可逆这点对排障场景是刚需，一条 FATAL 日志的细节一个字都不能裁掉。

官方用四种真实 MCP 输出格式做了基准测试：SRE 排障场景 55,957 token 压到 24,340（省 57%），代码库探索省 42%，GitHub issue 分诊省 30%，代码搜索省 21%。压缩本身耗时 0.21 毫秒（10K token 的 JSON）到 1.4 毫秒（100K token），不进 agent 延迟。答案质量上，GSM8K 压缩前后都是 0.870，SQuAD v2 在 19% 压缩率下保持 97%，BFCL 工具调用在 32% 压缩率下保持 97%。

接入形态有四种：Python/TypeScript 库里直接 compress(messages)；headroom proxy 起一个零代码改动的代理；headroom wrap claude 等命令包装编码 agent，官方兼容表列了 18 种，其中 16 种能一条命令接管，wrap Claude Code 时会顺带注册 Serena 语义导航 MCP；MCP 原生的客户端用 headroom mcp install。除了输入侧，它还管模型回话的输出 token，通过 verbosity steering 和 effort routing 削减，官方给出的估算是 31.7%（含 95% 置信区间，也支持留 10% 会话做对照实测）。另外 headroom learn 会从失败会话里挖教训写进 CLAUDE.local.md，下一次会话开头就带上。

# 安装（CLI 只随 PyPI 包发，npm 上的 headroom-ai 是 TypeScript SDK）
uv tool install --python 3.13 "headroom-ai[all]"   # 隔离环境装 CLI
pip install "headroom-ai[all]"                     # 或直接进当前环境

# 选一种形态
headroom wrap claude            # 包装 Claude Code（含 Serena）
headroom proxy --port 8787      # 或起零改动代理
headroom mcp install            # MCP 客户端
headroom dashboard              # 看实时节省

text-to-cad — 给 agent 装上 CAD，一段话变成一个能送厂的 STEP 文件

![text-to-cad 建模演示](./texttocad-demo.png)

让 agent 写个网页已经很成熟，让它画一个能真正加工出来的零件是另一回事。3D 打印、钣金、CNC 要的是工程格式（STEP、STL）和壁厚、悬垂这类可制造性约束，不是一段渲染代码。text-to-cad 把这一套做成了 agent 插件：模型在本地生成，输出直接是制造格式，自带可制造性检查和工程图。

本地是它的分水岭。CAD 内核用 build123d 加 Open CASCADE 7.9，工业界用了多年的几何内核，跑在你自己机器上；cadgen 负责 STEP-first 的生成、校验和检查。agent 通过一组 skill 驱动它，插件同时起一个本地 MCP 服务器（cadgen mcp）和一个 CAD Viewer：在 Claude Code 里，模型以可旋转的 viewer 卡片出现在对话里；在只渲染文本的 agent 里，给一个浏览器链接。生成的模型可以直接对接 3D 打印、钣金和 CNC 制造服务下单，从 prompt 到打样没有断点。

安装路径覆盖主流 agent，Claude Code、Codex、Cursor、Gemini CLI、Grok Build、Copilot、Cline、Goose、OpenCode、Windsurf、Zed 都有各自的命令；插件市场没收的那批用 skills CLI 装。典型场景：「给一块 100×60 的铝板四角加 M3 沉头孔，出 STEP」，agent 写建模代码、跑可制造性检查、把文件落在本地；打印前也可以先让它检查壁厚和悬垂。第一次启动要联网下载 CAD runtime，遥测默认开启，介意的话 uvx cadgen telemetry off 关掉。

采用数据在涨：GitHub 19,660 stars，PyPI 上 cadgen 周下载约 1.5 万。这类工具的用户基数本来就窄（机械、硬件工程师），这个下载量的密度不低。
