今天两个工具站在 AI 开发的两条边缘线上：一个把渗透测试从季度外包变成每次提交的例行检查，一个把 AI 账单从"供应商说多少就是多少"变成可独立复核的收据。共同点是都不信任现状，一个不信任漏洞扫描器的误报，一个不信任计费方的账本。

Strix — 53K stars 的开源 AI 渗透测试 agent，每个漏洞都附上跑通了的攻击请求

![Strix 演示](./strix-demo.png)

传统漏洞扫描器的老问题：它给你一份"潜在风险"清单，每个条目都要人工确认是不是真的。Semgrep 报一个 SSRF，可能是参数没接用户输入；Burp Suite 报一个 XSS，可能是反射点在 JSON 响应里根本弹不出来。渗透测试的价值在于"跑通"，而跑通要靠人，人很贵，所以大多数团队一年只做一两次渗透测试，大部分时间漏洞在代码里等着。

Strix 的形态是一组跑在 Docker 沙箱里的自主攻击 agent。侦察、利用、后利用三个阶段各司其职，共享状态，像一个小型红队一样协作。发现可疑点之后，agent 会真的构造 payload 打过去，看响应，拿到能复现的完整请求和响应，才会把它写进报告。报 SSRF，报告里就有那个触发内网请求的 URL；报 SQL 注入，报告里就有跑通的注入语句。finding 本身就是 exploit，误报被结构性消灭。

工具箱是专业渗透测试者的标准配置：Caido HTTP 拦截代理做请求篡改，Playwright 浏览器测 XSS、CSRF、点击劫持和认证绕过，Python 沙箱写自定义 PoC，加上子域名枚举、指纹识别这类侦察能力。覆盖范围贴着 OWASP Top 10 走：注入（SQL/NoSQL/命令/SSTI）、SSRF/XXE/RCE、IDOR 和越权、JWT 攻击、原型污染，还有业务逻辑类，竞态、支付金额篡改、工作流绕过。业务逻辑恰恰是规则引擎最难抓、人工渗透最花时间的一类。

对日常开发最实用的是 CI 集成。headless 模式配合 GitHub Actions，每个 PR 只扫 diff 涉及的改动，发现漏洞就非零退出、阻断合并。第三方评测（andrew.ooo，7 月）给过一个真实数字：一个小功能 PR 的扫描跑了 4 分 12 秒，Claude token 花了约 $0.35，抓到一个真的 XSS。每次 PR 花几毛钱，换季度五万美元渗透测试做不到的持续覆盖，这个账划算。

# 安装（需要 Docker + 任一 LLM API key）
curl -sSL https://strix.ai/install | bash

# 配置模型，跑第一次扫描
export STRIX_LLM="anthropic/claude-sonnet-4-6"
export LLM_API_KEY="your-api-key"
strix --target ./app-directory

# CI 里无头跑，只扫 PR diff
strix --target https://github.com/org/repo -n

# 给 Claude Code / Cursor 装 agent 技能（4 个：扫描/修复/CI/托管平台）
npx skills add usestrix/strix

Inferock Bench — 本地代理给你的 AI 账单开独立收据，8 月 16 日 Product Hunt 发布

![Inferock Bench 演示](./inferock-demo.png)

AI 账单有一个结构性问题：计费方和记账方是同一个人。OpenAI 说这次调用失败了不收费，Anthropic 说这部分 token 命中了缓存按折扣价算。你没有独立记录，只能信。更常见的场景是：一个 API 调用返回 500，或者响应被截断，或者模型拒答了，你根本没意识到这次调用进了账单。付钱的人拿着最少的账目信息。

Inferock Bench 是一个跑在本地的计费审计代理。你的开发流量走 localhost 上的它，它转发给真实的供应商 API，同时给每一次调用留下独立事件记录：供应商上报的用量、对应价格、请求响应元数据、状态码、耗时、重试证据。然后 @inferock/measure 把这些记录算成一张收据，把三类损失分开列：已发生的花费、账单可界定的金钱损失、时间损失和发票核查暴露。成本追踪工具回答"你花了多少、花在哪"，它回答"有没有花冤枉钱"：被计费的空响应、拒答、截断输出、token 重算对不上、重复的请求 ID、缓存折扣丢失、供应商故障引发的重试。

它克制的地方很实在。README 里写了明确的边界：审计不了绕开代理的流量，不宣称每次 mismatch 都是供应商多收钱，没覆盖到的检查面会标成 not-openable 而不是假装干净。收据把"供应商可能认账的损失"和"尚未被承认的损失"分开展示，不把两类钱加起来制造更大的数字。创始人还主动披露：托管版 Inferock 是商业产品，评分标准 The Inferock Standard 是他们写的。利益冲突摆出来让你自己判断。
