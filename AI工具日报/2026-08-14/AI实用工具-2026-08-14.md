## DeepSeek Harness — 官方开源的插件化 Agent 框架，连 Agent Loop 都是插件

  今天早上开源，几小时内冲到 46,816 stars、3,717 forks。36kr 的报道标题是"Everything is a Plugin"——这不是口号，是架构事实。

  编码 Agent 这两年爆发，每个项目都在自己拼同一套东西：文件系统、终端、LSP、技能、子代理、会话管理。DeepSeek Harness（命令名 `dsh`）把这件事反过来做：底层是一个叫 Cordis 的微内核，运行中的 Harness 就是一个 Cordis Context，文件系统、shell、Web、技能、子代理、工作流、规划模式，每个能力都是独立包注册的插件。连 Agent Loop 本身也是一个插件，可以被替换。你想改循环策略，不需要 fork 整个项目，写一个插件挂上去就行。

  能力组装靠一个 `cordis.yml`。同一套代码，挂 TUI 插件是终端 Agent，挂 Web 插件是浏览器应用，换成 Headless 入口就是批处理命令行，换成 ACP 或 JSON-RPC 就是可被其他程序驱动的自动化服务。配置文件支持 overlay 分层，TUI 和 Web 共享基础配置再各自加界面插件。

  工具调用也不是"拿到函数名就执行"。一次调用要过 pre-policy、不可逆安全守卫、执行、后处理、结果组织、结果通知整条流水线，权限、超时、重试、指标统计都能挂在不同位置。工具可以声明"某些参数下并发安全"，调度器会把连续的只读任务并行跑，碰到写操作或安全性未知的调用就当作 barrier，等前面的任务全部结束再独占执行。

  上手就一行，启动 Web UI：

```bash
# Node.js 环境直接跑，Web UI 默认在 http://127.0.0.1:3080
npx @deepseek-ai/dsh web

# 源码方式
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness && pnpm install && pnpm run build && pnpm dsh web
```

  目前是 developer preview，官方明确说了会有 breaking change，适合尝鲜和读架构，生产环境再等等。

## Stagehand v4 — 浏览器 Agent SDK 重大更新，直接住进浏览器扩展

  浏览器自动化是 AI Agent 的刚需，但 Playwright 是为测试设计的，Agent 用它有三个硬伤：页面快照又大又乱、嵌套 iframe 抓不到、每步操作都要跨进程往返。Stagehand 从 2024 年起就专门解决这些问题，现在 v4 把解决方案推到了更彻底的位置：整个 SDK 以浏览器扩展形式运行，和页面住在同一个进程里，所有操作的往返延迟直接归零。

  v4 的三件套 API 没变，但能力全部重写。`act()` 用自然语言执行操作，`observe()` 看页面上哪些元素可交互并返回精确 selector，`extract()` 抽取结构化数据，全部带自愈能力——网站改版后会自动刷新操作方式，不用重写脚本。新增的能力包括：nested iframe 的深度定位器、closed Shadow DOM 支持、WebMCP、clipboard 操作、批量命令、OpenTelemetry 埋点。页面快照做了混合 accessibility tree 裁剪，Agent 拿到的上下文刚好够用，token 消耗明显下降。

  一个例子看它的用法：

```typescript
import { browserbase, Stagehand } from "@browserbasehq/stagehand";
import { z } from "zod/v4";

const browser = await browserbase.launch();
const stagehand = await Stagehand.create({ browser });
const page = await browser.context.pages()[0];
await page.goto("https://github.com/browserbase");

await stagehand.act("click on the stagehand repo");
const { data: actions } = await stagehand.observe("find the latest PR");
await page.locator(actions[0].selector).click();
```

```bash
npm install @browserbasehq/stagehand zod
```

  TypeScript、Python、Go 三个 SDK 同步更新。8 月 12 日的 Show HN 上维护者提到，v4 已经给 LangChain DeepAgents、Mastra、Vercel eve、CrewAI 做了参考集成，这几个 Agent 框架的用户可以直接接入。

### 同类工具对比

| 工具 | 安装方式 | 核心特点 | 价格 | 热度 |
|------|---------|---------|------|------|
| **Stagehand v4**（今日推荐）| `npm install @browserbasehq/stagehand` | 扩展内运行，自愈 act/observe/extract | 开源 MIT | ⭐ 23.8K |
| Playwright | `npm install playwright` | 为测试设计，确定性最强，Agent 场景要自己适配 | 开源 Apache-2.0 | ⭐ 90K+ |
| Browser Use | `pip install browser-use` | 自然语言驱动浏览器的 Python 库 | 开源 MIT | ⭐ 40K+ |
| Playwright MCP Server | 微软官方 MCP | Agent 直连浏览器工具 | 开源 MIT | ⭐ 60K+ |

  选 Stagehand 的理由是它只做一件事：为 Agent 设计的浏览器接口。Playwright 和 Browser Use 都比它 stars 高，但前者要自己处理快照和 iframe，后者抽象层次更高、调试时不易看到底层发生了什么。Playwright MCP Server 前几天刚推荐过，v4 这次是 3.x 到 4.x 的架构重写，属重大更新，纳入今日推荐。

⭐ 23,809 · v4.0 · MIT · [GitHub](https://github.com/browserbase/stagehand) · [文档](https://stagehand.dev)

## 其他值得关注

  **Warp Agent CLI**（8 月 4 日发布）。Warp 终端把自己的多模型 Agent 拆出来做成独立 CLI，Ghostty、iTerm 2、VS Code、Windows 终端都能用。内置模型路由按任务复杂度自动选模型，PowerShell 一行安装：`Invoke-RestMethod "https://app.warp.dev/download/agent-cli.ps1" | Invoke-Expression`。订阅 $18/月起，也可自带 API key。降级理由：和前几天推荐的 grok-build 同属终端编码 Agent，热度未能拉开数量级。

  **Verdent**。🏪 VS Code Marketplace · ⬇ 36,883 installs · [安装](https://marketplace.visualstudio.com/items?itemName=VerdentAI.verdent)。主打 SWE-bench Verified 成绩压过 Claude Code 和 Codex 的生产级 Agent，Plan First 先拆任务再写码，内置 verifier 子代理检查产出。降级理由：VS Code 扩展领域两天前刚推过 GoCodeo，安装量同级，不满足领域去重豁免。
