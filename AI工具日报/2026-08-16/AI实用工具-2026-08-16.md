## diagram-design — 一个 Claude Code 技能，让 AI 画的架构图过得了设计评审

![[diagram-design-demo-1.png]]

  让 AI 给文档配一张架构图，出来的通常是同款圆角框加几个箭头，和产品官网的气质差了十万八千里。自己进 Figma 调配色要半小时，放弃配图又显得文档没写完。diagram-design 把这个痛点做成了一个 Agent Skill，装在 Claude Code、Codex 或 Pi 里，一句话就能生成编辑级质量的图表。

  它的做法是把 27 种图表类型（架构图、时序图、泳道图、ER 图、甘特图、象限图、飞轮图等）全部做成自包含的 HTML + SVG 模板，没有构建步骤、没有 JavaScript、没有外部图片依赖。三种静态变体随取随用：minimal light、minimal dark、full-editorial。设计约束写得像家规：1px 细线边框、禁阴影、圆角不超过 10px、所有坐标和间距必须能被 4 整除。单一强调色加一个珊瑚色焦点节点，把视线钉在图上最重要的位置。

  与品牌对齐靠一步 onboarding：把公司网址交给它，它会抓取配色并映射成语义 token（paper、ink、accent），顺手做一遍 WCAG AA 对比度校验。已有的 draw.io 或 Mermaid 源文件也能救回来：import 之后按你选的格式、尺寸、细节等级重绘，明确不保留 Mermaid 的自动布局。

  README 的口号是 "no Mermaid-slop"。这个仓库本周在 GitHub Trending 上新增 14,735 stars，总量 18.7K，fork 1.1K，MIT 协议，CI 覆盖三大平台，README 里连几何标签重叠检测、文档同步这类脚本门禁都配齐了。作者 Cathryn Lavery 是 BestSelf.co 的创始人。

```bash
# Claude Code 插件安装
/plugin marketplace add cathrynlavery/diagram-design
/plugin install diagram-design@diagram-design

# Codex
codex plugin marketplace add cathrynlavery/diagram-design
codex plugin add diagram-design@diagram-design
```

  装好后直接说 "Make me an architecture diagram of my app"，或者从模板起步：`cp skills/diagram-design/assets/template.html my-diagram.html`。审阅画廊在 skills/diagram-design/assets/index.html，在线版在 cathrynlavery.github.io/diagram-design。

## Blackbox Agent — 2,912,750 安装量的多 Agent 编排层，15 个编码 Agent 一个入口

  每家 AI 实验室都有自己的编码 Agent：Claude Code、Codex、Gemini CLI、Goose、OpenCode。各有各的强项，也各有各的订阅和工作流。Blackbox Agent 做的事是把它们装进一个 VS Code 扩展里，任务同时派给多个 Agent，一个 Judge 层评估所有输出，自动挑出最好的那份实现。

  与"又一个 AI 助手"不同，它的核心是编排：同一任务可以并行发给 Claude Code、Codex、Gemini 等 15+ 个编码 Agent，也可以排成流水线，一个写、一个审、一个优化。300+ 模型（Claude Sonnet 4.6、GPT-5.4、Gemini 3.1 Pro 等）随时切换。Agent 能读代码库、写文件、跑终端命令、读输出、自我修正直到交付，每一步操作都在你的授权下进行，还能启动真实浏览器验证自己写的页面。

  对日常开发最实用的两件事：MCP 服务器直连，把数据库、API 或内部服务接给 Agent；Blackbox Skills 把团队的可复用工作流打包成技能，版本化进仓库，由 Agent 自主调用。

  免费安装，连接 BLACKBOX AI 账户即可用，30 秒上手，无需 API key 和信用卡。

```bash
# VS Code 扩展视图 (Ctrl+Shift+X) 搜索 "BLACKBOX AI" 安装
# 或命令行
code --install-extension Blackboxapp.blackboxagent
```

  距上次推荐 Agent 编排类工具（DeepSeek Harness，8 月 14 日）仅两天，但 Blackbox 的 290 万安装量是它的 62 倍，按同领域重磅新秀收录。
