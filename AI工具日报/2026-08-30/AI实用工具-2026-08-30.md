# AI 实用工具 · 2026-08-30

![[summary.png]]

  今天的两个工具在回答同一个问题：Agent 越来越多地替你干活，谁来给它接系统，谁又盯着它改了什么。

## AnythingMCP：自托管网关，把任何 API/数据库变成 Agent 连接器

  给 Claude、ChatGPT、Cursor 接入你已有的系统，常见两条路：等官方出 MCP server，或者自己写一个。AnythingMCP 走第三条：一个自托管的 MCP 网关，把 REST、SOAP/WSDL、GraphQL、SQL/NoSQL 数据库甚至其他 MCP server 导入后直接暴露成连接器，一行 SDK 代码都不用写。导入方式覆盖 OpenAPI/Swagger、Postman、cURL、WSDL、GraphQL introspection，工具名、描述、参数都能在可视化编辑器里调整，决定 Agent 看到什么的是你。

  它不只是管道。网关会为每个 workspace 构建一张连接器数据关系的知识图谱，通过 MCP 回喂给 Agent，让它跨系统串联调用工具时知道谁跟谁关联；团队里工具的真实用法还会被提炼成可复用的 AI skills。这两块都可选，关掉之后它就是纯粹的转发网关。企业向的能力也没落下：OAuth2、RBAC 角色权限、完整审计日志，Caddy 自动配 HTTPS。

  自带 175+ 预置适配器是它的特色：Deutsche Bahn、weclapp ERP、Etsy、Shopware、DHL 这类常见集成一键导入，填个凭证就能用。同一条连接器可以同时服务 Claude、ChatGPT、Gemini、Copilot 和 Cursor，搭一次处处可用。

```bash
# 需要 Docker 24+、bash、openssl
git clone https://github.com/HelpCode-ai/anythingmcp.git
cd anythingmcp && ./setup.sh
# setup 完成后打开 http://localhost:3000，第一个注册的账号自动成为 admin

# 或手动部署
cp .env.example .env && docker compose up -d
```

## Flare：依赖图当主界面的 agentic IDE，盯着 Agent 改代码

  编码 Agent 在终端里跑的时候，你对它改动的了解基本只剩聊天记录和 git diff。Flare 把整个代码库画成一张活图：每个文件是一个节点，每条 import 是一条边。图下面嵌一个完整终端，跑 claude、codex 或 opencode。Agent 改文件的瞬间图上就变，谁改的标在谁头上。哪些文件被重写、这些文件又被谁 import，影响范围一眼可见。

  每一波改动都会快照进本地 shadow history，可以按文件或整棵树 diff、回滚。Agent 的写入波及到其他文件引用时，Flare 会把你拉进来确认。任务分发走 MCP：Agent 从看板领任务干活，人和图在旁边看着。桌面应用或浏览器模式都行，数据不出本机，无账号，MIT。

  测试方面作者下了功夫：350+ 单元测试、73 个 Playwright 端到端测试，覆盖桌面和浏览器两种模式。8 月 2 日开源，22 日上 Product Hunt，目前 v1.1.0。

```bash
git clone https://github.com/AlgoNoRhythm/Flare
cd Flare
npm install
npm run build
npm start   # 或从 Releases 页下载预编译包
```
