e2e — agent 写的测试步骤通过一次就缓存，之后重放不花 token

![e2e 演示](./e2e-demo.png)

E2E 测试一直卡在两难里。用 Playwright 或 Cypress 自己写，选择器脆、UI 一改就要人来修；把整条用例交给 AI，每次 CI 都要模型现场决策，慢、贵，而且每次走的路径可能都不一样。TesterArmy 开源的 e2e 想同时解决这两头。

做法是在同一个测试文件里混写两种步骤。确定性的部分照旧：screen.getByRole 定位、expect 断言；自然语言的部分用 agent.act('upgrade the workspace to the Pro plan') 表达目标，agent.assert 判断屏幕。关键机制在缓存：一个被后续断言证实通过的 agent.act 步骤会被记录进 .e2e/cache/，下一次运行直接重放，不再调用模型；应用变了，才从当前界面交回给 agent 接着做。agent.assert、agent.waitFor、agent.extract 始终实时判断，不缓存。

引擎分两套：Web 用 Playwright 驱动 Chromium/Firefox/WebKit，移动端驱动 iOS 模拟器和 Android 模拟器。npx e2e init 的向导会写好配置、示例测试、agent 技能和 MCP 配置（Claude Code 的 .mcp.json 与 Cursor 的 .cursor/mcp.json）；e2e mcp 让编码 agent 能自己开浏览器，locate 工具会验证 screen.* 选择器并把可用的测试代码还给你。CI 模式自动开启，重试一次、缓存只读；v0.17 起 --strict-cache 会让过期的录像以 REPLAY_STALE 直接失败，而不是悄悄放行。

数据：8,447 stars，403 forks，Apache-2.0，7 月 22 日建仓。npm 上 e2e 周下载 60,933，历史累计 147,934。它 10-05 冲上 GitHub 日趋势榜首，单日涨星 1,400 以上；v0.16 把安装依赖从 117 个包砍到 29 个，体积约 36MB 降到 31MB。两件要注意的：CLI 默认开启匿名遥测，不采集测试内容与凭据，E2E_TELEMETRY_DISABLED=1 可关。官方建议 Node 24.8+，Windows 上走 WSL。

# 在应用目录里初始化：向导选择 Web 或 Mobile，以及模型来源
npx e2e init

# 跑测试。通过验证的 agent 步骤会写进 .e2e/cache/，下次重放不再调模型
npx e2e run

claude-mem — 5 个钩子自动记住一切，新会话自动接上

![claude-mem 演示](./claude-mem-demo.gif)

新开一个会话，第一句话往往是重新解释项目背景；上个会话查到的结论、试错过的路径，全没了。CLAUDE.md 只装得下你亲手写下来的结论，装不下「上次做到哪了」。

claude-mem 以 Claude Code 插件的形式运行，挂了 5 个生命周期钩子：SessionStart、UserPromptSubmit、PostToolUse、Stop、SessionEnd。会话里的工具调用被自动捕获成 observation，用 Claude Agent SDK 压缩成语义摘要，写进本地的 SQLite（FTS5 全文检索）加 Chroma 向量库；新会话开始时，SessionStart 钩子把相关时间线注入上下文。查询通过 4 个 MCP 工具分三层走：search 先拿一个带 ID 的轻索引，timeline 看上下文，get_observations 才取详情，先筛后取，官方给的说法是比整篇塞进上下文省约 10 倍 token。

安装两条命令，重启后生效。数据都在本机 ~/.claude-mem/，支持 28 种语言生成摘要，项目目录里会自动长出带活动时间线的 CLAUDE.md。除 Claude Code 外也支持 Codex、Gemini、Copilot、OpenCode、OpenClaw 等。

数据：98,998 stars，8,673 forks，Apache-2.0，2025 年 8 月建仓，最近提交在 10-09。有一个商业模式要提前知道：安装后向导会引导浏览器登录，登录后送 30 天不占订阅额度的 observer，到期自动回落到你的 Anthropic 订阅，或改用自己填的 OpenRouter / Gemini key；不想登录的话加 --provider 参数，或设 CLAUDE_MEM_ONLINE_OPTIN=false，安装照样完成。另外它默认每次工具调用都触发一次压缩，成本敏感的人可以看看下表的 lite 版。

i-have-adhd — 10 条规则，让 agent 把答案放在第一行

![i-have-adhd 图标](./i-have-adhd-logo.png)

和编码 agent 对话有个固定槽点：先复述问题，再铺垫背景，最后才说结论。你问「改哪个文件」，得先读三段解释。以前只能靠「先说结论」这种口头提醒，i-have-adhd 把它做成了一套可安装、可开关的规则。

规则一共 10 条，核心理念是按能直接执行的形状输出：答案或下一步动作放第一行，命令、路径、代码片段优先；多步工作编号，每步只放一个有界动作；结尾给一个两分钟内能做完的下一步；当前问题没结束不抛新问题；每轮复述进度（「5 步里第 3 步完成」）；时间估计给具体单位，不许说「一会儿」；改完代码说清现在什么能用了；报错按位置、原因、修法三段给；列表最多 5 条；不写开场白、不复述、不写结尾客套。另有 4 条例外：被要求解释时正常展开；破坏性操作先确认；连续三次修不好就停下来点名那个没验证过的假设；需求有歧义时只问一个短问题。

安装是 Claude Code 插件的两条命令，敲 /i-have-adhd 才生效，默认装着不生效是刻意设计的，SKILL.md 里标了 disable-model-invocation。想每会话常开，创建一个哨兵文件 touch ~/.claude/.i-have-adhd-always，SessionStart 钩子就会自动加载整份规则，说一句 stop adhd mode 可以在当前会话关掉。规则文件本身可以 fork 改；除 Claude Code 外，Codex、Cursor、GitHub Copilot、Gemini/Antigravity、Grok、Pi 等 13 个平台都给了对应的安装方式。

数据：56,139 stars，3,199 forks，MIT，2026 年 5 月建仓，最近提交在 10-06；今天（10-10）还在 GitHub 趋势榜上，榜单快照显示单日新增 318 stars。
