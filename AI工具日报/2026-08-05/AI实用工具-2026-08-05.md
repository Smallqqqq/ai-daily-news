# AI 实用工具 · 2026-08-05

![[summary.png]]

  今天的两个工具站在 AI 辅助开发的两个极端：一个在 agent 准备大展拳脚之前，从七级台阶上把它一步步拽下来，告诉它「别写，浏览器已经有了」；另一个把整个计算机的控制权交给 agent——键盘、鼠标、浏览器、手机——然后用每次任务的经验自动长出一棵技能树。

## Ponytail — 把最懒的资深工程师塞进 AI agent，代码量直降 54%

  你用 Claude Code 或 Codex 让 agent 写一个日期选择器。agent 热情洋溢地创建了 3 个文件、50 行代码、引入了一个第三方日期库，还开了个关于时区处理的讨论线程。Ponytail 让 agent 在动手之前先爬七级台阶——爬到第一级「这东西真的需要存在吗？」就停了，然后写下一行 `<input type="date">`，因为浏览器 2012 年就已经有了日期选择器。

  这不是比喻。Ponytail 是 2026 年 7 月 28 日发布的一个开源工具，由一个 npm install 命令安装，然后用两个 Node.js 生命周期钩子嵌入 AI 编码 agent 的决策链路。它的核心是一套**七级"为什么非要写"阶梯**（YAGNI Ladder）：agent 在理解需求之后、写代码之前，依次检查——这东西真的需要存在？仓库里是否已经有了？标准库是否已经提供了？平台（浏览器/OS）是否内置了？已安装的依赖是否已经干了这件事？能不能就一行？——只有当六级台阶全部踏空，才允许写"能跑的最少代码"。

  但这里有一个关键细节：**懒惰不等于疏忽**。校验逻辑、错误处理、安全防护、无障碍访问，这四样东西永远不在砍削范围之内。Ponytail 只砍过度工程，不砍防御代码。它的设计前提是 agent 已经充分理解了问题——它懒惰的是方案，不是阅读。

  作者在一个真实仓库上用 Claude Code 跑了对照实验。结果：启用 Ponytail 后，生成的代码量减少 54%，API 费用减少 20%，完成任务的速度快 27%，同时安全守卫保留率 100%。在那些 agent 最容易过度建造的任务上，代码量最多减少了 94%。

  Ponytail 提供了三档强度——`lite`（温和提醒）、`full`（默认，阶梯式审查）、`ultra`（宁可不够也不要多余）——外加几个辅助命令：`/ponytail-review` 审查当前 diff 是否有过度工程，`/ponytail-audit` 扫描整个仓库，`/ponytail-debt` 把被砍掉的捷径记录到技术债账本里，以备将来确实需要时还能找回来。

```bash
npm install
npx .
```

  安装后会提示选择目标 agent——支持 Claude Code、Codex、Copilot CLI、OpenCode、Pi、Antigravity、Hermes、OpenClaw 等九种主流 AI 编码工具。插件通过 Node.js 生命周期钩子工作，需要 node 在 PATH 中；如果不在，技能依然可用，只是自动化激活会静默跳过。

## GenericAgent — 3,300 行代码的自我进化 agent，用完即成长，6 倍省 token

  大多数 agent 框架的哲学是"把尽可能多的能力预装进去"——于是你得到一个几十万行代码、数百个模块的庞然大物。GenericAgent 反其道而行：核心只有约 3,300 行 Python 代码，Agent Loop 不到 100 行，但它每次完成一个任务，就把执行路径自动结晶成一个可复用的 Skill——能力不靠预装，靠进化。

  它的设计极其直白：7 个原子工具（在最新版本中是 9 个）加上一个约 100 行的 Agent Loop。这 7 个工具分别控制浏览器、终端、文件系统、键盘、鼠标、屏幕视觉和 ADB 连接的移动设备。每个工具只做一件事，组合起来却覆盖了计算机控制的全部维度。没有 LangChain 的抽象层，没有 Playwright 的浏览器驱动——它用 `pywebview` 直接注入真实浏览器窗口，保留登录态，连 hCaptcha 人机验证都能直接通过（因为对于网站来说，这就是一个真实用户在操作）。

  自我进化机制是 GenericAgent 最特别的地方。每次你让它完成一个任务——比如"帮我在美团上点一杯奶茶"——它经历完整的感知→规划→执行→验证链条后，会把这个任务的执行模式自动提炼成一个 Skill 文件。下次再遇到类似任务，不需要重新推理——直接调用 Skill。用了一个月之后，你的 GenericAgent 能做的事情和第一天完全不同。作者甚至声称整个 GenericAgent 仓库——包括安装 Git、执行 `git init`、写 commit message——全部是由 GenericAgent 自己自主完成的，作者从未打开过终端。

  在 token 消耗上，GenericAgent 有显著优势：它的上下文窗口需求不到 30K token，而同类 agent 通常需要 200K 到 1M token。用作者的话说，"更少的噪声，更少的幻觉，更高的成功率，更低的成本"。它支持 Claude、Gemini、Kimi、MiniMax 等主流模型。

```bash
git clone https://github.com/lsdefine/GenericAgent.git && cd GenericAgent
uv venv && uv pip install -e ".[ui]"
cp mykey_template_en.py mykey.py   # 填入你的 LLM API key
```

  注意需要 Python 3.11 或 3.12（不要用 3.14，与 `pywebview` 不兼容）。

### 同类工具对比

| 工具 | 安装方式 | 核心特点 | 价格 | 热度 |
|------|---------|---------|------|------|
| **GenericAgent**（今日推荐）| `pip install genericagent` | 3.3K 行种子代码，自进化技能树，真实浏览器注入 | 开源 MIT | ⭐ 13.7K |
| OpenClaw | `git clone` + 多服务编排 | 开源 skill agent 框架，53 万行代码 | 开源 | ⭐ 更高 |
| Claude Code | `npm install -g @anthropic-ai/claude-code` | Anthropic 官方终端 agent，文件+终端控制 | $20–200/月 | ⭐ 广泛使用 |
| OpenHands | `pip install openhands` | AI 驱动开发平台，默认沙箱容器执行 | 开源 | ⭐ 较高 |

  GenericAgent 和 OpenClaw 代表了两种哲学：GenericAgent 从 3.3K 行种子代码出发，靠自我进化长能力；OpenClaw 从 53 万行代码出发，把能力预先建造好。Claude Code 定位更偏向软件工程任务，对系统的控制范围（文件+终端）不如 GenericAgent 全面（浏览器+键鼠+ADB）。如果你需要的是"给 AI 一台完整的电脑让它自己摸索"，GenericAgent 是当前最轻量的选择。
