今天两个工具，一个在「怎么让 agent 变成你自己的」这件事上推到极致，一个解决 n8n 工作流进不了版本库、agent 改不动流程的老问题。

Pi 1.0 — 111K stars 的极简 agent harness 发布 1.0，把当年拒绝的 MCP 也收编了

![Pi 终端界面演示](./pi-demo.png)

终端里的编码 agent 这两年分成两派。一派是 Claude Code 这样的全能平台，功能齐全，但你对它怎么工作几乎没有发言权；另一派默认你必须接受作者想好的那套流程。Pi 走第三条路：内核保持极小，除默认工具外几乎一切都能被替换。扩展、技能、提示模板、主题都是插件，打包成 Pi package 后走 npm 或 git 分发。官方 README 的原话是 Adapt Pi to your workflows, not the other way around。子 agent、plan mode 这类功能它默认不做，你想要就自己装一个，或者让 Pi 现场给你写。

1.0 在 10 月 1 日发布，最大看点是 Codemode。Pi 此前长期明确拒绝 MCP，理由是协议可组合性差、工具定义白吃 token。现在它把 MCP 工具转成 JavaScript 沙箱里可组合的脚本：agent 能在一次脚本执行里批量调用工具，工具定义延迟到真正需要时才加载。Earendil 官方博客把这次转向写进了「You Said No MCP!」一文。态度很直接：与其在外面反对，不如进来把它改好。同一个版本还带来虚拟模型（用 Opus 规划、GPT 实现、由 Jev 判断何时切换）和 Anthropic 缓存预热。终端界面也重做了，默认全屏。

热度上这周没有对手。GitHub 111,793 stars，MIT 协议。10 月 1 日的 HN 帖拿到 1442 分、475 条评论。项目由 Mario Zechner（libGDX、OpenClaw 作者）创建，今年春天并入 Earendil。Earendil 的联合创始人包括 Flask 作者 Armin Ronacher，投资方有 Accel、Balderton，以及 n8n、OpenClaw、Revolut、Slack 的创始人。一个极简 harness 能拉到这种背书，说明可改造性已经被当成正经生意在做。OpenClaw 就是跑在 Pi 之上的真实集成案例。

安装走官方脚本，Windows 有对应的一行命令；需要 Node 22.19+：

# macOS / Linux
curl -fsSL https://pi.dev/install.sh | sh

# Windows PowerShell
powershell -c "irm https://pi.dev/install.ps1 | iex"

# 或直接走 npm
npm install -g --ignore-scripts @earendil-works/pi-coding-agent

使用前注意：Pi 刻意不带权限系统，默认以你本机的用户权限直接运行。官方给了三条隔离路线。Gondolin 扩展把内置工具路由进本地 Linux micro-VM；纯 Docker 隔离整个进程；OpenShell 走策略沙箱。同期还发布了实验性的 Pi Durable，面向需要跨界面、跨会话长时间运行的多方 agent 应用。

n8n-as-code — 把 n8n 工作流拉进 Git，再给编码 agent 一份完整的 n8n 词典

![n8n-as-code 工作流同步演示](./n8n-as-code-demo.png)

n8n 的痛点用过的人都知道。工作流是存在实例里的 JSON，没有版本历史，改坏了回滚靠手动导出导入。让 AI 帮忙改，它又不知道 537 个节点的参数长什么样，全靠猜。n8n-as-code 把仓库变成 n8n 的开发工作区。n8nac pull 把工作流拉成本地文件，还能转成带装饰器的 .workflow.ts，人和 agent 都好读。改完 n8nac push --verify 先过 schema 校验再推送，冲突走 diff 视图解决。同步是显式的，不敲命令，什么都不会发生。

面向 agent 的是它的技能层：537 个节点的 schema、文档、示例、7702 个模板和校验规则打包成 AI Skill。Claude Code 里一条 /plugin 命令装完，之后 agent 能自己走「查节点 → 写工作流 → 校验 → 推送」整条流程。VS Code / Cursor 里的 Agent Workbench 用的是同一套契约。多环境管理是另一个加分项。promote --from Dev --to Prod 会重写目标环境元数据、重映射凭据，并在 n8nac-promotion.json 里记录稳定绑定，等于把 CI 里跑熟的那套发布流程搬到了 n8n 上。配套的 n8n-manager 还能在本机用 Docker 起受管实例，带隧道。

V2 已经取代 V1 成为默认版本线。项目 1,588 stars、MIT 协议、独立开发者维护（与 n8n 官方无隶属关系），VS Code Marketplace 和 Open VSX 都可安装。
