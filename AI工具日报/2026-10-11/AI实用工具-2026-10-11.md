## OpenQodex — push 之前，让另一个 agent 先审一遍

![[openqodex-demo-1.png]]

　　10 月 5 日 GitHub 开源了 ReviewBench：219 个真实 PR、2,623 个已知缺陷，七款主流审查工具同台跑。头名 Copilot Code Review 精度 87.8%，召回率 26.0%，报出来的基本都是真问题，但已知缺陷里它只找到四分之一。托管审查的定位一直是「宁可少报，不报错」，可这个召回率配不上「把审查交给它」。另一头，agent 写代码越来越快，人在 push 前那一眼越来越潦草。

　　OpenQodex 把审查挪到你本机、push 之前。`openqodex review` 先圈定改动范围：还没 push 的 commit 加上所有未提交内容。然后按改动文件类型挑扫描器跑静态检查。13 个内置：semgrep、gitleaks、bandit、ruff、oxlint、osv-scanner、actionlint、hadolint、shellcheck、golangci-lint、brakeman、rubocop、sqllint。只保留落在改动行上的发现，全库扫描的历史噪音直接过滤。接着开一个全新的 Claude Code（或 Codex）进程当 reviewer，读的是冻结的改动副本，没有写代码那个会话的设置、插件、hook 和记忆。写代码的 agent 不审自己的代码，是产品写死的规则。reviewer 必须对每条扫描器发现给出保留或驳回的理由，脚本再校验它是否真看过每一行改动；任何环节没跑完，直接打印「Review incomplete」并说明缺什么，不假装审完了。

　　安装一条命令，自动发现机器上的 Claude Code、Cursor、Codex、Cline 并写入适配文件。push gate 挂在 Claude Code / Codex 的 PreToolUse hook 上，只在 `git push` 时触发，默认只警告；仓库里配了 `review.block_on_severity` 才真的拦。另有 git pre-push hook 兜底，任何工具发起的 push（包括手敲的）都先过一遍扫描，还有 GitHub Action 在 PR 上跑全量审查。一次审查 1 到 3 分钟。

　　数据：568 stars、38 forks、Apache-2.0，10 月 10 日深夜还在推 commit。它不需要额外的 API key，跑的是你已有的 Claude Code / Codex 订阅额度，跟托管产品按 PR 计费的模型完全不同，边际成本约等于零。报告落成一份单文件 `report.html`，每条发现挂在对应对的代码行下面，还附上改动的调用面（谁调了、谁 import 了）。

```bash
# 初始化：发现机器上的 Claude Code / Cursor / Codex / Cline，写适配文件
npx openqodex init

# push 前审查改动；--all 审整库，review '#42' 审指定 PR
npx openqodex review

# 给 Claude Code 装 skill，之后直接说"review my change with openqodex"
npx skills add openqodex/openqodex
```

## Verdent — VS Code Marketplace 上 SWE-bench 成绩最硬的编码 agent 扩展

![[verdent-demo-1.png]]

　　大多数 VS Code 里的 AI 编码扩展是「聊天框加补全」：一句模糊需求丢进去就直接开工，边写边猜，写完你才发现方向不对。Verdent 把 Plan 拆成了独立阶段：只读模式，先分析代码、问澄清问题，产出一份带可视化逻辑图的结构化实现方案；你可以逐条让它改方案，满意了再点 Start Building 切执行。方案可编辑、可评审，这一步比事后读 diff 便宜得多。

　　Verify 是另一处差异。它有一个专门的 verifier subagent 加浏览器工具，自动跑测试、点页面、抓问题，写代码的 agent 不参与自证。官方演示里，verifier 会输出一份逐项验证清单：构建通过、功能覆盖、代码质量、安全性，再附上确认可用的功能列表。执行阶段支持贴截图作多模态输入，实现要贴着图比对；改动走 Code Diff 审查。另有 subagent 机制、项目 rules 和 MCP 支持。

![[verdent-demo-2.png]]

　　数字：官方技术报告称 SWE-bench Verified pass@1 76.1%、pass@3 81.2%，并强调没有榜单调优、没有 test-time scaling，跑分的就是用户能装到的生产版本。Marketplace 描述里他们直接写「生产级 agent（含 Claude Code 与 Codex）中最高的 SWE-bench Verified 成绩」，这是官方口径，但 76.1% 的 pass@1 放在编码 agent 里确实是第一梯队。分发数据也扎实：38,945 次安装、4.5 星、45 个评价，v1.6.13，仍在迭代。

```bash
# VS Code Marketplace 安装（发布者 Verdent AI）
code --install-extension verdentai.verdent
```
