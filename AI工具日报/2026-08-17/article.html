DBHub — 一个 MCP 服务器管五种数据库，默认上下文只有竞品十分之一

agent 查数据库这件事，过去一年最大的变化是官方参考实现退场了。PostgreSQL 官方 MCP server 和 SQLite 参考实现都停在 archived 状态，README 顶格写着不再提供安全保证。需求没消失。Stack Overflow 2025 调查里 PostgreSQL 以 55.6% 首次反超 MySQL，成了最常用数据库。把 schema 探索、SQL 起草交给 agent 的人越来越多。Bytebase 的 DBHub 冲着这个空档做了一个零依赖进程，同时接 Postgres、MySQL、MariaDB、SQL Server、SQLite 五种引擎。

它把 token 成本当成第一约束。多数数据库 MCP 会把整套 schema 一次性灌给模型。DBHub 默认只开两个工具：execute_sql 和 search_objects。schema 信息走渐进披露，模型先搜表、再搜列、再决定查询。仓库给出的对比：默认配置喂给模型的上下文约 1.4K token，MCP Toolbox 是 19.0K，Supabase MCP 是 19.3K。explain_sql（只看执行计划不跑查询）和 health_check（连接池状态、缓存命中率）是显式 opt-in，不进默认工具面。内置一个叫 Workbench 的 web 界面，不接任何 MCP 客户端也能在浏览器里跑查询、看请求轨迹。

本地开发时连 Claude Code 问 schema、验证 SQL；生产排障用只读账号加防 runaway 查询的守卫。最实用的用法是给非技术同事发一个 .mcpb 安装包。双击安装、填连接串即用，engine 层面就拒绝写操作，不用教他们改 JSON 配置。

# Claude Code 直连本地 Postgres
claude mcp add --transport stdio dbhub -- npx @bytebase/dbhub@latest --transport stdio --dsn "postgres://user:password@localhost:5432/dbname"

# 或者起一个 HTTP 服务给团队共用
npx @bytebase/dbhub@latest --transport http --port 8080 --dsn "postgres://..."

Needle 2 — 14MB 的 agentic 模型，500 tok/s 跑在树莓派上

![needle-demo-1](./needle-demo-1.png)

这是初代 Needle 的换代版本，本周在 HN 刷到 532 分。45M 参数压到 2bit，整个模型是单个 14MB 二进制，跑满一个会话只占 28MB 内存。树莓派 5 上解码 500 token/s。Quest 3S 和 Vision Pro 这类 VR 设备 400-1,500，200 美元以下的三星 A 系列手机 300-700。作者的说法：边缘 AI 一直等于 Mac 和 PC，那只是 210 亿 IoT 设备里的 15 亿。

省算力的关键在架构。Simple Attention Network 用 Hadamard MLP 替换 FFN。正交 Walsh-Hadamard 变换在 n log n 时间内完成，没有权重可读。attention 和 MLP 两条残差都做 sandwich-norm 加门控。推理端还有个 byte-level grammar，从你声明的 schema 编译出来，约束输出的每个 token。工具调用直接返回结构化数据。256-token 滑动窗口，工具定义作为 KV sink 钉住，会话再长内存也停在 28MB。每个响应带校准过的置信度分数，高于阈值就执行，低于就升级到云端大模型。

它主攻函数调用、设备控制、结构化提取三类任务，不做开放式聊天：enum 字段当分类器，提取字段当摘要器。官方推荐玩法：fine-tune 几分钟到几小时，做出产品专属的工具词汇。再配合私有 DeepSeek-v4-Flash 部署，低置信度请求才升级。企业级任务的推理成本压到接近零。

pip install cactus-needle

注册工具用装饰器，函数签名给参数类型，docstring 就是工具描述，run() 把「选工具 → 执行 → 回传结果」整个循环走完。

![needle-demo-2](./needle-demo-2.png)

benchmark 上 Needle 2 与 FunctionGemma 270M、LFM2.5 230M、Apple Foundation Model 互有胜负，体积是对方的 1/5 到 1/70，对方 f16 它 2bit。每 token 的 MFLOPs 直接折算成毫瓦时：Needle 70，同参数挤压版 87，常规 transformer 164。
