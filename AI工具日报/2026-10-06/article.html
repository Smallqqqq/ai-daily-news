ponytail — 让 AI 像最懒的资深工程师那样写代码

让 agent 加个缓存，它给你一个 48 行的 CacheManager 类；让它加个日期选择，它顺手装上三个新依赖。代码是写出来了，但 review 要人看，依赖要人升级，多出来的每一行都在后面收利息。agent 的默认倾向是“多做”，因为做多不需要解释。

ponytail 是一套约束规则，核心是七级阶梯。动手写之前，agent 必须停在第一个能站住的台阶上：不需要的功能直接跳过（YAGNI，投机需求不做）；代码库里已有现成的就复用；标准库能做就用标准库；平台原生够用就用原生；已装的依赖能解决，绝不加新依赖；一行能搞定就写一行；全部排除完，才写最小可行版本。顺序有讲究：先读懂改动涉及的代码、追清真实流程，再选台阶，对方案偷懒，对阅读不偷懒。削减也有边界，输入校验、错误处理、安全和无障碍不在偷懒范围内。

三个强度档：lite 按需求实现但顺口提一句更省事的路子；full 默认强制走阶梯；ultra 自称 YAGNI 极端分子，直接甩一行方案并质疑需求本身。除了写代码时的约束，还有三个审查命令，/ponytail-review 扫当前 diff 里的过度设计并给出删除清单，/ponytail-audit 扫全仓臃肿，/ponytail-debt 把主动推迟的捷径记成台账，避免“以后再说”变成失踪人口。官方给的例子是一个 48 行的 CacheManager 被换成一行 lru_cache，行为不变，少 48 行。

官方在 FastAPI + React 仓库上跑了 12 个真实功能任务：代码量平均少写 54%（最高 94%），token 少 22%，成本低 20%，速度快 27%，安全性验证 100% 保留。作者修正过早期口径，那个“少 80–94%”是被基线话术放大的假象，已按 agentic 实测数据改掉。仓库 156,024 stars，8,383 forks，MIT。官方标注支持 20 种 agent，npm 周下载 23,348。

MCP Toolbox — Google 官方的数据库 MCP，20 多种库一套工具

![MCP Toolbox 演示](./mcp-toolbox-demo.png)

让 agent 查数据库，每接一种库就要重写一遍 MCP server：连接池、认证、SQL 注入面、工具描述，全是重复劳动，还各写各的风格。agent 缺的是一条安全、参数化、说得清的查询通道。

MCP Toolbox 是 Google 开源的数据库 MCP 服务器，两种用法。预置模式一条命令：--prebuilt=postgres 直接得到 list_tables、execute_sql 这类通用工具，连上就能查，嫌工具多还能按子集加载（--prebuilt=postgres/data 只加载 SQL 工具）。自定义模式是它的另一半：tools.yaml 里声明数据源、参数化 SQL、工具集，还可以定义 prompt 和 resource，把“生产环境允许 agent 做什么”写成一份能进代码评审的配置文件。连接池、IAM 认证、OpenTelemetry 观测都是内置的。

典型场景有两个。轻的是在 IDE 里随口问“上周注册的用户里有多少复购”，agent 调 execute_sql 当场算给你看；重的是把业务查询封装成具名工具，比如 search-hotels-by-name，SQL 固定、参数化、只读，agent 只能按你划定的范围查。数据库覆盖 20 多种，PostgreSQL、MySQL、MariaDB、SQL Server、Oracle、MongoDB、Redis、Elasticsearch、ClickHouse、Snowflake、Neo4j 到 Google Cloud 的 BigQuery、Spanner、AlloyDB、Firestore 都在列。最近还加了一条反向路径：skills-generate 可以从 tools.yaml 直接生成 Agent Skill 安装包。

数据方面，16,596 stars、1,749 forks，Apache-2.0，最新 v1.13.1（9 月 25 日），本周仍在活跃提交。npm 包周下载 85,099。Python / JS / Go / Java 四种语言 SDK 齐备，还有一个 ./toolbox --ui 交互式界面，可以先把工具手测一遍再交给 agent。项目原名 genai-toolbox，近期改名 mcp-toolbox。老用户一条 git remote set-url 就完成迁移。

# 最快：往 mcp.json / claude_desktop_config.json 里加这段，npx 直接拉起带预置工具的服务器
npx -y @toolbox-sdk/server --prebuilt=postgres --stdio

# 按自己的 SQL 和工具集来，就配一份 tools.yaml
npx @toolbox-sdk/server --config tools.yaml

# 也有 Homebrew 和源码安装
brew install mcp-toolbox
go install github.com/googleapis/mcp-toolbox@v1.13.1
